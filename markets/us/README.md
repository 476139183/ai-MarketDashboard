## 四只美股分时数据采集

采集对象为美股闪迪 `SNDK`、海力士美股存托凭证 `SKHY`、美光 `MU` 和英伟达 `NVDA`；SKHY 不是韩股 000660。

```bash
python3 markets/us/collect_sessions.py          # 采集一次
python3 markets/us/collect_sessions.py --watch  # 持续运行，每 5 分钟采集
python3 markets/us/session_audit.py            # 按标的和时段检查来源及成交量
```

数据写入本地 `markets/us/.cache/session-bars.sqlite3` 的 `bars` 表，按标的和时间去重，包含美东交易日、时段、价格、成交量、来源和北京时间采集时间。按美东时钟划分盘前 04:00–09:30、常规 09:30–16:00、盘后 16:00–20:00；节假日和提前收盘日未采用交易所日历，时段标签仅表示钟面区间。

优先 Yahoo 的 1 分钟 K 线（请求最近 5 天含盘前盘后）；失败时使用 Nasdaq 当日分时采样，采样点不是真实 OHLC，成交量为空，不能用于计算成交量加权 VWAP。采样点不会覆盖已保存的 Yahoo K 线。数据源可能限流、延迟或缺失，采集结果会逐标的显示错误和最新数据时间，无法保证完整；持续采集依赖命令保持运行，不会自动在后台启动。现有 ORB 策略仍是常规时段策略，扩展时段的数据不代表经过验证的盘前或盘后交易信号。

数据审计的 `vwap_ready` 仅检查来源和成交量是否具备必要条件，不证明数据完整，也不代表策略已经回测。当前旧回放中 ATR 会使用同日完整日线或全天范围，存在前视偏差；历史回放结果不能作为可靠的收益证明。

### Massive 免费历史分钟数据

到 [Massive](https://massive.com/) 注册 Stocks Basic 免费账号并取得 API Key，在终端中配置环境变量后导入（请勿把 Key 写入仓库或聊天）：

```bash
export MASSIVE_API_KEY='你的 API Key'
python3 markets/us/massive_import.py
python3 markets/us/session_audit.py
```

默认请求最近 30 个自然日，截至前一个美东日期；也可指定 `--start 2026-09-01 --end 2026-10-28`。免费套餐的当日数据通常要等美东午夜后。导入支持分页及四只股票，保留真实 OHLCV 并优先于 Nasdaq 采样和 Yahoo 缓存；某一标的失败不会阻止其他标的。延长时段无成交或成交不满足聚合条件可能没有 K 线，不能将空分钟直接当作完整数据。API 的实际覆盖与账号权限需要实测，当前导入尚未用真实账户验证。

### Alpaca 免费实时 IEX 分钟线

`alpaca_live.py` 每 30 秒读取四只股票最新的 IEX 分钟 K 线，`--watch` 时持续运行，保存在独立的 `markets/us/.cache/iex-live.sqlite3`，与 Massive 历史数据分开。需要环境变量 `APCA_API_KEY_ID` 和 `APCA_API_SECRET_KEY`：

```bash
python3 markets/us/alpaca_live.py --watch
python3 markets/us/session_audit.py --db markets/us/.cache/iex-live.sqlite3
```

接口返回的 K 线只有最新一根；网络中断或进程停止期间可能漏数据，不保证盘前盘后覆盖。超过 5 分钟的返回值标记为过期、不写库；休市时过期属于正常。IEX 是单交易所行情，不代表全市场成交量，无法当作全市场 VWAP。Alpaca 凭证已验证；时段内数据覆盖仍需在交易时段实测。采集器默认不会启动或后台持续运行。

### 分时段探索性回放

```bash
python3 markets/us/session_replay.py
```

仅使用本地 Massive OHLCV；按盘前、常规、盘后分别以该时段开头两根 15 分钟 K 线建立开盘区间；仅纳入整个时段每个 15 分钟桶都有数据的日期，提前收盘及有空桶的日期被排除，使用上一交易日常规时段高低差作为波动代理；用分钟典型价和成交量近似 VWAP。K 线收盘产生信号，下一根开盘尝试入场，按实际入场价检验收益风险比至少 0.8；同一 K 线同时碰止盈止损时先按止损处理，每时段最多一笔，时段结束平仓。不计手续费、点差或滑点，下一根开盘无延迟成交是假设，盘前盘后只是原策略的探索性迁移；不宜据此认定策略可实盘。筛除缺失时段可能造成样本选择偏差；即使每个 15 分钟桶都有数据，也不代表每分钟都有成交。结果写入本地 `.cache/session-replay.json`。

趋势研究可用 `--trend-filter`：15 分钟短线趋势得分 ≥ 2 只允许做多，≤ −2 只允许做空，其他分数观望。`--target-pct 2` 将目标设为实际入场价上下 2%，并重新检查风险收益比；它不是保证单笔收益 2%。例如：

```bash
python3 markets/us/session_replay.py --trend-filter --output markets/us/.cache/trend-replay.json
python3 markets/us/session_replay.py --trend-filter --target-pct 2 --output markets/us/.cache/trend-target2-replay.json
```

趋势与目标变体仅用于研究，不自动修改看板实时信号。样本外可固定为 2026-08-01 及之后，不能将多次试参后的这段数据当作未接触过的最终验证集。

低频研究可通过 `--trend-threshold 3 --target-pct 2.2 --min-reward-risk 1 --min-range-pct 3` 测试：趋势得分同向至少 3、以上一常规交易日高低差与当前时段开盘价之比筛选波动、止盈为入场价的 2.2%、入场收益风险比至少 1。手续费/滑点不在回放中自动扣除；若另行假设双边总成本为 0.2 个百分点，2.2% 毛收益约等于 2% 净收益。参数为探索性研究，不用于实时看板，已经查看过的测试期不是全新留出集。

`python3 markets/us/trend_breakout.py` 可回放探索性的常规时段突破策略：15 分钟收盘后，趋势分数同向至少 3、收盘突破开盘区间并处于 VWAP 代理值同侧；下一根开盘尝试入场，最近两根 K 线结构止损，2.2% 毛止盈。昨日常规交易振幅至少 3%，止盈风险比至少 1；最多每交易日一笔。`--trend-threshold 4` 测试更强趋势。两版均为研究用途，不代表实时看板已启用；未计成本，样本期间已被查看不能视作全新验证集。

### 按信号持仓回放

```bash
python3 markets/us/signal_hold.py
```

常规时段 15 分钟收盘首次出现做多或做空信号后，于下一根开盘价模拟入场；随后只要每根收盘信号仍与持仓同向就继续持有，变为观望、平仓或相反方向则于下一根开盘价模拟退出；常规时段结束时强制平仓，同一日可再次入场。无固定止盈止损、不计成本和滑点。收盘信号至下一根开盘假设零延迟，属于理想化；该版本只使用现有看板开仓信号，观望可能只是价格不在新开仓区间，并不必然代表已有仓位失效，因此不能当作已验证的持仓策略。

`python3 markets/us/signal_hold.py --mode structure --output markets/us/.cache/structure-hold.json` 用持仓结构退出：入场仍使用现有做多/做空信号，首次信号的结构止损固定保留；后续收盘为观望但方向结构未变时继续持有，结构变为震荡或反向、或出现对应平仓信号时在下一根开盘退出。15 分钟内触及止损时按止损价模拟成交，跳空则使用更差的开盘价；只知 K 线无法确定止损在该 15 分钟内的具体时刻。收盘强平，未计交易成本和其他滑点，次根开盘成交为理想假设。该策略为研究用途，未启用到实时看板。

### 逐分钟入场、15 分钟持仓判断

`python3 markets/us/intraminute_hold.py` 使用完整美股常规时段 1 分钟 OHLCV 回放。开盘 30 分钟 ORB 形成后，每根 1 分钟线收盘重新计算现有策略（当前 15 分钟桶为截至该分钟的部分数据）；首次出现做多/做空信号时尝试在下一分钟开盘入场。持仓期间每根 15 分钟线收盘才检查结构；结构不再同向或出现对应平仓信号时下一分钟开盘退出。初始结构止损按分钟 K 线触发并考虑开盘跳空；收盘强平。无固定止盈，不计成本、额外滑点；无法在历史数据中模拟真正逐笔即时成交或缺失成交。筛除不足 390 根分钟 K 线的常规时段可能造成样本选择偏差。回放不改看板实时信号。

### 首次信号与人工离场机会

`python3 markets/us/first_signal_quality.py` 基于已生成的 `intraminute-hold.json`，每只股票每天仅取第一笔实际满足模拟成交条件的交易，用本地分钟高低价检查退出前是否曾有 2% 的毛收益机会。若同一分钟同时碰到结构止损和目标且此前未到目标，记为顺序不明并保守按止损先处理。方向趋势分数使用信号时可见的数据，阈值筛选只是对已成交的首次信号做事后分组，不代表被过滤后可用后续信号替代的独立策略回测。触价不等于成交，不含成本；已反复用于参数比较的时间段不是独立留出样本。

### 盘前高低点与开盘突破（研究）

`python3 markets/us/premarket_breakout.py` 用当地 04:00–09:30 的盘前分钟线确定盘前区间；开盘 30 分钟内首次一分钟收盘突破盘前高低点时，下一分钟开盘模拟入场，信号时已出现的开盘极值作为止损；分钟线检查止损，每 15 分钟检查收盘价是否失去常规时段累计典型价成交量加权均价，失效则下一分钟开盘退出，收盘强制退出。每只股票每天最多一笔，无真实逐笔成交、无费用和额外滑点；同分钟触及目标与止损时顺序不明，机会统计保守处理。盘前没有 K 线的分钟不能证明没有成交，盘前高低点受数据覆盖影响。候选规则由对 2026-10-21 的事后观察提出，期间已被反复观察，任何训练/测试划分均不能视为真正独立的前瞻验证。该规则未接实时看板。

持仓回放可选 `--confirmations 2` 测试连续两根 15 分钟同方向开仓信号；默认值 1 保持首次信号入场。两根确认会延迟首次入场，也可能漏掉短暂机会，只作为研究对比，不自动修改看板。
