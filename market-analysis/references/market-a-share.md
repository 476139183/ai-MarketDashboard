# A股市场规则（覆盖层）

在 [analysis-rules.md](analysis-rules.md) 共用框架之上，分析 **沪/深/北交所股票、ETF、可转债（若用户指定）** 时必须叠加本节。与 [market-us.md](market-us.md) **互斥**：不得把美股盘前、RTH、融券默认做空套到 A股。

## 识别

- 代码：6 位数字；可带 `SH`/`SZ`/`BJ` 或 `sh.`/`sz.` 前缀。
- 板块：主板、创业板（300）、科创板（688）、北交所（8/4 开头等）、ST/\*ST、ETF。
- 产品：默认 **A股现货**；融资融券、股指/期权、港股通须单独标明，规则不可混。

## 时段与日历（北京时间）

| 阶段 | 时间（北京） | 分析含义 |
|---|---|---|
| 早盘集合竞价 | 约 9:15–9:25 | 可写竞价观察；**不**当连续竞价盘中信号已确认 |
| 上午连续竞价 | 9:30–11:30 | 盘中 |
| 午休 | 11:30–13:00 | 非交易；价格冻结为午前 |
| 下午连续竞价 | 13:00–15:00 | 盘中；收盘集合竞价规则以交易所为准 |
| 收盘后 | 15:00 后 | 仅复盘/次日预案；不称「当前可成交盘中价」除非另有盘后产品 |

- 主时间轴已是北京时间，**无需**换算美东。
- 有效期：默认至**该 A股交易日 15:00**；跨日必须重评。
- 节假日/半日市：以交易所日历为准，休市不发可执行入场价。

## 涨跌停与流动性

- 先核对本板涨跌幅限制（主板约 ±10%，创业板/科创板约 ±20%，ST 更窄，新股/注册制首日等例外）。
- **触板/封板**时：流动性与可成交性改变；不得按普通 VWAP 回踩假设随意给大单入场。
- 一字涨停/跌停：默认 **观望**（无法按计划入场或止损滑点失控），除非用户只要结构说明。
- 支撑压力触及涨跌停价时，须写明「受涨跌停约束」。

## T+1 与动作语义

- **现货默认 T+1**：当日买入，次一交易日才能卖出。做多预案须写清：当日止损若依赖卖出，对**当日新开仓**可能无法执行 → 优先用「能否接受隔夜」约束仓位，或改观望。
- 信号用词：
  - 普通现货账户：**做多 / 观望** 为主；
  - **做空**仅当用户明确持有融券额度、或分析股指/期权/其它可空产品时才允许；否则禁止输出现货「做空」可执行单。
- 卖出已有持仓叫「减仓/止盈/止损退出」，不叫做空。

## 盘中信号（A股适配）

共用仍遵循：**关键位 S → E → T1**、R1≥0.8。差异如下：

| 项 | A股口径 |
|---|---|
| 确认周期 | 默认 **5 分钟**收盘；可升 15 分钟 |
| ORB | 用 **9:30 起前 15/30 分钟** 高低作开盘区间（非美股 RTH）；集合竞价价不单独冒充 ORB |
| VWAP | 日锚定、连续竞价成交；缺量则不写 VWAP 结论 |
| 盘前 | A股无美股式盘前连续竞价；竞价阶段只给观察，不给「盘前已触发做多」 |
| 做空 | 见上；无融券前提时三选一改为 **做多 / 观望**（或「仅结构偏空，不可空」） |
| 有效期 | 至当日 15:00（北京） |

**观望加则（A股）**：临近涨跌停且封单不明；T+1 下止损不可当日执行且用户未接受隔夜；午休仅有午前价却称为午后已确认。

## 基本面与公告

- 优先：巨潮资讯、上交所/深交所/北交所披露、公司公告、定期报告。
- 财报季、解禁、减持、增发、重组、监管函须单独时间戳。
- 估值用人民币与 A股股本口径；不与美股 ADR 价格直接横比。

## 高波动 / 题材股

- 单日近涨跌停、或 ATR/现价显著偏大时：区间改「带」，确认必须用分钟收盘；禁止点位幻觉。
- 题材炒作段：反弹默认当情绪脉冲，反转需收盘级结构修复，不单凭大阳线改向。

## 与美股对照（禁止混用）

| 禁止 | 原因 |
|---|---|
| 用 EDT/盘前盘后模板写 A股 | 时段模型不同 |
| 默认输出 A股现货做空 E/S/T1 | 多数账户不可空 |
| 用 Nasdaq/Alpaca 作 A股现价主源 | 覆盖与延迟不对 |
| 把美股 ORB（含盘前）公式原样套用 | 开盘机制不同 |
| 忽略涨跌停谈止损可执行性 | 触板无法按价成交 |
