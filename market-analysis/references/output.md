# 输出契约

中文直接给判断。动作写「做多、做空、观望、平空、平多」。美股 V 反收复 VWAP 时第一句必须能写到 **平空**（不能只写观望）。A股普通现货未确认可空时用「做多、观望」或「结构偏空、不可空」。按问题删减。

## 市场标注（强制）

开头标明：**市场 = A股 | 美股 | 加密**（及产品：现货/融券/永续等）。规则与数据源须与市场一致。

## 时间口径

- 对外一律**北京时间**，例：`2026-10-27 14:05（北京）`。
- **美股**需要对照时写 `北京 / EDT`；常规盘夏令约北京 21:30–次日 04:00，冬令 22:30–次日 05:00。
- **A股**主轴已是北京时间；有效期默认至当日 15:00，勿写美东钟点。

## 完整分析

开头 2–3 句：市场与标的、**信号**、关键分界、数据截至北京时间。用 5x 压测说明止损宽窄（非默认满仓）。

基本面 4–6 项；关键位表；多空/情绪表（口径分列）。执行表：

| 执行项 | 区间 / 条件 | 依据 |
|---|---|---|
| 信号 | 做多 / 做空 / 观望 | A股现货默认无做空则勿填做空 |
| 止损 S | 触发价 + 关键位类型 | 禁止纯百分比 |
| 入场 E 带 | `[E_min, E_max]` | 相对 S 的 5x 压测 |
| 止盈 T1 | 必填 + R1 | 缺则改观望 |
| 5x 压测 | 触及 S 回撤% | ≥35% → 不合格 |
| 有效期 | 该市场当日收盘（北京） | A股≈15:00；美股≈次日 04:00/05:00 |
| A股附加 | 涨跌停约束、T+1 可否当日止损 | 不可执行则观望或降仓说明 |

## 盘中更新

1. 第一句：市场 + 信号 + 现价 + 北京时间。
2. 做多/做空同屏 **E、S、T1、R1、5x%**。
3. 一句依据（写清用的是 A股 ORB 还是美股 RTH ORB）。
4. 缺数据 → 观望并写缺项。

## 复盘 / 预演

每笔开仓 + 结局（T1/S/收盘）。时间用北京时间。

## 调用示例

- `$market-analysis` **A股** 盘中更新 600519：做多/观望 + E/S/T1，注意涨跌停与 T+1。
- `$market-analysis` **美股** 盘中更新 SNDK：做多/做空/观望 + E/S/T1，北京时间，5x 压测。
- `$market-analysis` 分析 BTCUSDT Binance 永续，比较资金费与 OI。

固定默认：北京时间、方向必附 T1、5x 作压测；**先标市场再给价**。
