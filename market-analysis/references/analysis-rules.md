## 美股盘中信号：ORB + VWAP（规范框架）

对齐通行日交易写法（ORB 突破 + VWAP 偏向过滤、假突破反转、结构止损），**不**追求「必打低多高空」，只要求多空单合理、可解释、可风控。

### 1. VWAP = 偏向；ORB = 结构生死线

| 位置 | 偏向 |
|---|---|
| 价 > VWAP | 偏多：优先做多，不做逆势空 |
| 价 < VWAP | 偏空：优先做空，不做逆势多 |

**平仓（防噪音打损后踏空）**：

- 空单：**收复 ORB 上沿** 才平空（不是毛刺穿一下 VWAP 就平）。
- 多单：**跌破 ORB 下沿** 才平多。

不要求必须当日成交；可等回踩/反抽进带。

### 2. ORB 同向突破（主策略）

- ORB ≈ 开盘后前 30 分钟（引擎：首 2 根 15m）。
- **做多**：已上破 ORB 上沿且在 VWAP 上、未追飞；**S = ORB 下沿外侧**；T1 用 ORB 量度/前高（可更远）。
- **做空**：已下破 ORB 下沿且在 VWAP 下、未追飞；**S = ORB 上沿外侧**（容忍反抽到 VWAP，避免贴脸止损后次日踏空）；T1 用量度/前低。
- 回踩/反抽默认只观察、**不开仓**（噪音易当日打损）。不强制当日平仓，可持有到结构失效。
- 逆 VWAP 突破不做。

### 3. VWAP 回踩 / 反抽

- 入场可在 VWAP 附近，但 **止损仍挂 ORB 对侧**，不把 VWAP 当唯一生死线。
- 离开入场带不追 → 观望。

### 4. 假突破反转（更严）

- 假跌破后须 **站上 ORB 上沿** 才评反转多；假涨破后须 **跌破 ORB 下沿** 才评反转空。

### 5. 风控

| 条件 | 处理 |
|---|---|
| R1 &lt; 0.7 或价序错误 | **禁止新开** |
| 5x 压测 | **仅参考，非硬闸、非默认满仓** |
| 未到带 / 已离带 | **观望（勿追）** |

### 6. 输出动作

`做多` / `做空` / `观望` / `平空` / `平多`。第一句写清动作与 setup 名称。

看板实现：`markets/us/dashboard/engine.py` → `compute_intraday_signal`。

## 策略契约摘要

完整分析仍给优先方向与 E/S/T1。盘中以规范 setup 为准；数据不足则等待确认，不编造价位。
