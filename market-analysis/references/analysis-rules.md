## 美股盘中信号：短期趋势 + ORB + VWAP

看板默认 **仅 15m**。对齐通行 ORB+VWAP，并用短线趋势过滤；**禁止追涨杀跌**。

### 0. 短期趋势（开仓闸）

当日 15m：`EMA5/13`、斜率、价相对快线、近端结构；**|score|≥2** 认定趋势。ORB≈开盘 **30 分钟**（2×15m）。

| 趋势 | 允许 |
|---|---|
| up（score≥2） | 普通多：ORB 上破后的回踩 / 趋势回踩 |
| down（score≤−2） | 普通空：ORB 下破后的反抽 |
| flat | **普通多空不开** |
| 例外 | **低位多·洗盘**：冲高回落日不要求 score（深洗时常短暂极负） |

T1 拉远；收盘浮盈≥1.5% 可兑现。

### 1. VWAP = 偏向；ORB = 结构生死线

| 位置 | 偏向 |
|---|---|
| 价 > VWAP | 偏多：优先做多，不做逆势空 |
| 价 < VWAP | 偏空：优先做空，不做逆势多 |

**平仓**：空单收复 **ORB 上沿** 才平空；多单跌破 **ORB 下沿** 才平多（勿因 VWAP 毛刺平仓）。

### 2. 主策略优先级（回溯后）

1. **低位多·洗盘**（冲高回落日优先）：路径曾上破 ORB 上沿、又下破 ORB 下沿，现价仍在 ORB 下沿上方 → 结构偏多；入场 **[ORB下+缓冲, VWAP]**；贴日高/ORB 上沿 **不追**。勿把洗盘段做成粘性空。
2. **ORB 同向突破后回踩/反抽**：多回踩偏 VWAP 侧（上沿远离 ORB/日高）；空反抽偏 VWAP 侧（下沿远离 ORB/日低）。
3. **趋势回踩/反抽**：须短线同向；离开入场带不追。

### 3. 假突破反转（更严）

假跌破后须站上 ORB 上沿才评反转多；假涨破后须跌破 ORB 下沿才评反转空。

### 4. 日线过滤（开仓第二闸）

先看 15m 信号，再用现价相对 **MA20** 的日线偏向：

| 日线 | 处理 |
|---|---|
| 偏空 | **禁止普通多**；允许 `低位多·洗盘`（标注逆日线） |
| 偏多 | **禁止普通空** |
| 与盘中同向 | 不额外阻挡 |

### 5. 风控

| 条件 | 处理 |
|---|---|
| 贴日高/ORB上（多）或贴日低/ORB下（空） | **观望（不追涨杀跌）** |
| R1 &lt; 0.8 或价序错误 | 可标方向，**entry_ready=否**（仅预案） |
| 未到带 / 已离带 | **观望** |

### 6. 输出动作

`做多` / `做空` / `观望` / `平空` / `平多`。第一句写清动作与 setup（如 `低位多·洗盘`）。

看板：`markets/us/dashboard/engine.py` → `compute_intraday_signal`。

## 策略契约摘要

完整分析仍给优先方向与 E/S/T1。盘中以规范 setup 为准；数据不足则等待确认，不编造价位。
