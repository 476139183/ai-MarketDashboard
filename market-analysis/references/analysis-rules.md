## 美股盘中信号：ORB + VWAP（规范框架）

对齐通行日交易写法（ORB 突破 + VWAP 偏向过滤、假突破反转、结构止损），**不**追求「必打低多高空」，只要求多空单合理、可解释、可风控。

### 1. VWAP = 日内偏向

| 位置 | 偏向 |
|---|---|
| 价 > VWAP | 偏多：优先做多 setup，不做逆势空（除非假涨破确认） |
| 价 < VWAP | 偏空：优先做空 setup，不做逆势多（除非假跌破确认） |

收复/跌破 VWAP：对旧仓发 **平空 / 平多**（翻面附近），避免扛反向单。

### 2. ORB 同向突破（主策略）

- ORB = 常规盘前约 30 分钟（引擎用首 2 根 15m）高低。
- **做多**：上破 ORB 上沿 **且** 价在 VWAP 上方；S 在 ORB 中轴/VWAP 失效侧；T1 用 ORB 量度或前高。
- **做空**：下破 ORB 下沿（或开盘向下驱动）**且** 价在 VWAP 下方；S 在 ORB 沿/中轴；T1 用 ORB 量度或前低。
- 逆 VWAP 的突破：**不做**（过滤假突破噪音）。

### 3. VWAP 回踩 / 反抽（延续）

- 多头：已偏多时，回踩 VWAP～ORB 上沿一带做多；S = VWAP 下。
- 空头：已偏空时，反抽 ORB 下沿～VWAP 一带做空；S = VWAP 上。
- 离开入场带不追价 → **观望**。

### 4. 假突破反转

- 假跌破：向下驱动后 **收回并站上 VWAP** → 可做多；S = ORB 下沿外侧（不是无远日低硬绑）。
- 假涨破：向上驱动后 **跌破 VWAP** → 可做空；S = ORB 上沿外侧。

### 5. 风控硬闸（多空共用）

| 条件 | 处理 |
|---|---|
| R1 = \|T1−E\|/\|E−S\| < 0.8 | **禁止新开** |
| 5×\|E−S\|/E ≥ 35% | **禁止新开** |
| 价序错误（多非 S\<E\<T1 / 空非 T1\<E\<S） | **禁止新开** |
| 未到带 / 已离开带 | **观望（勿追）** |

5x 满仓只作压测尺子，不是默认仓位。

### 6. 输出动作

`做多` / `做空` / `观望` / `平空` / `平多`。第一句写清动作与 setup 名称。

看板实现：`markets/us/dashboard/engine.py` → `compute_intraday_signal`。

## 策略契约摘要

完整分析仍给优先方向与 E/S/T1。盘中以规范 setup 为准；数据不足则等待确认，不编造价位。
