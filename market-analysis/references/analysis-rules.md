## 美股盘中信号：短期趋势 + ORB + VWAP

对齐通行写法，并用 **15m 短期趋势** 过滤逆势单以提高胜率。

### 0. 短期趋势（开仓硬闸）

周期可选 **1m / 5m / 15m**（看板切换；逻辑同一套）。用当日该周期：`EMA5` vs `EMA13`、快线斜率、价相对快线、近端结构；**|score|≥2** 认定趋势。ORB≈开盘 **30 分钟**（1m×30 / 5m×6 / 15m×2）。

| 趋势 | 允许 |
|---|---|
| up | **做多**：ORB 上破或 VWAP 回踩续多 |
| down | **做空**：ORB 下破或 VWAP 反抽续空 |
| flat | **不开仓**（不猜方向） |

胜率可降，核心是跟短线趋势。T1 拉远；收盘浮盈≥1.5% 可兑现，否则拿到 T1/S。

### 1. VWAP = 偏向；ORB = 结构生死线

| 位置 | 偏向 |
|---|---|
| 价 > VWAP | 偏多：优先做多，不做逆势空 |
| 价 < VWAP | 偏空：优先做空，不做逆势多 |

**平仓（防噪音打损后踏空）**：

- 空单：**收复 ORB 上沿** 才平空（不是毛刺穿一下 VWAP 就平）。
- 多单：**跌破 ORB 下沿** 才平多。

不要求必须当日成交；可等回踩/反抽进带。

### 2. ORB 同向突破（主策略）

- ORB ≈ 开盘后前 30 分钟（引擎：首 2 根 15m）。
- **做多**：已上破 ORB 上沿且在 VWAP 上、未追飞；**S = ORB 下沿外侧**；T1 用 ORB 量度/前高（可更远）。
- **做空**：已下破 ORB 下沿且在 VWAP 下、未追飞；**S = ORB 上沿外侧**（容忍反抽到 VWAP，避免贴脸止损后次日踏空）；T1 用量度/前低。
- 逆 VWAP 或逆短期趋势突破不做。
- 不强制当日平仓；收盘浮盈可兑现，浮亏可拿到结构失效。

### 3. 趋势回踩 / 反抽

- 给出观察带，**默认不开**；止损参考 ORB 对侧。离开入场带不追。

### 4. 假突破反转（更严）

- 假跌破后须 **站上 ORB 上沿** 才评反转多；假涨破后须 **跌破 ORB 下沿** 才评反转空。

### 5. 风控

| 条件 | 处理 |
|---|---|
| R1 &lt; 0.8 或价序错误 | **禁止新开** |
| 5x 压测 | **仅参考，非硬闸、非默认满仓** |
| 未到带 / 已离带 | **观望（勿追）** |

### 6. 输出动作

`做多` / `做空` / `观望` / `平空` / `平多`。第一句写清动作与 setup 名称。

看板实现：`markets/us/dashboard/engine.py` → `compute_intraday_signal`。

## 策略契约摘要
