## 美股盘中信号：短期趋势 + ORB + VWAP

对齐通行写法，并用 **15m 短期趋势** 过滤逆势单以提高胜率。

### 0. 短期趋势（开仓硬闸）

用当日 15m：`EMA5` vs `EMA13`、快线斜率、价相对快线、近端抬高/降低结构；**|score|≥3** 才认定趋势。另要求：多单价≥当日开盘、空单价≤开盘；ORB 突破须 **连续两根收盘** 站在区间外。

| 趋势 | 允许 |
|---|---|
| up | 只做多（ORB 上破站稳；回踩仅观察） |
| down | 只做空（ORB 下破站稳；反抽仅观察） |
| flat / 偏弱 | **不开仓**，观望 |

### 1. VWAP = 偏向；ORB = 结构生死线

| 位置 | 偏向 |
|---|---|
| 价 > VWAP | 偏多：优先做多，不做逆势空 |
| 价 < VWAP | 偏空：优先做空，不做逆势多 |

**平仓（防噪音打损后踏空）**：

- 空单：**收复 ORB 上沿** 才平空（不是毛刺穿一下 VWAP 就平）。
- 多单：**跌破 ORB 下沿** 才平多。

不要求必须当日成交；可等回踩/反抽进带。

### 2. ORB 同向突破（主策略）

- ORB ≈ 开盘后前 30 分钟（引擎：首 2 根 15m）。
- **做多**：已上破 ORB 上沿且在 VWAP 上、未追飞；**S = ORB 下沿外侧**；T1 用 ORB 量度/前高（可更远）。
- **做空**：已下破 ORB 下沿且在 VWAP 下、未追飞；**S = ORB 上沿外侧**（容忍反抽到 VWAP，避免贴脸止损后次日踏空）；T1 用量度/前低。
- 逆 VWAP 或逆短期趋势突破不做。
- 不强制当日平仓；收盘浮盈可兑现，浮亏可拿到结构失效。

### 3. 趋势回踩 / 反抽

- 短期趋势明确时给出观察带，**默认仍不开仓**（等 ORB 同向突破确认）。
- 止损参考仍挂 **ORB 对侧**；离开入场带不追 → 观望。

### 4. 假突破反转（更严）

- 假跌破后须 **站上 ORB 上沿** 才评反转多；假涨破后须 **跌破 ORB 下沿** 才评反转空。

### 5. 风控

| 条件 | 处理 |
|---|---|
| R1 &lt; 0.7 或价序错误 | **禁止新开** |
| 5x 压测 | **仅参考，非硬闸、非默认满仓** |
| 未到带 / 已离带 | **观望（勿追）** |

### 6. 输出动作

`做多` / `做空` / `观望` / `平空` / `平多`。第一句写清动作与 setup 名称。

看板实现：`markets/us/dashboard/engine.py` → `compute_intraday_signal`。
