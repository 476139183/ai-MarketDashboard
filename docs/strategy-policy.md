## 各类型分别处理

| 类型 | 策略与验证约定 |
|---|---|
| 加密货币永续合约 | 01～11属于这一研究分组；新增币种、交易所、周期仍须重新验证，核对资金费、标记价、成本、流动性与强平模型 |
| 加密货币现货 | 单独研究；不能直接照搬永续合约的双向交易、杠杆和资金费假设 |
| 国内商品期货 | 独立的日线月份合约研究；双均线20/60与唐奇安20/10仅为待验证基准，核对乘数、保证金、费用、交割及换月；不自动接入模拟账户 |
| A股原股 | 沿用A股独立研究链路；按对应证券的交易日历、交易与结算限制及成本验证 |
| 美股原股 | 美股独立策略；区分盘前、常规盘、盘后以及各时段的数据和成交条件 |
| 美股相关交易所合约 | 独立于美股原股和加密货币；使用实际合约规则、报价、交易时间、资金费与流动性验证 |

基础指标与行情展示组件可以复用；交易决策规则、参数、选型结论和收益记录必须按市场、产品、交易所、标的与周期明确归属。数据或适配缺失时应标为未验证，不自动套用另一市场的默认策略。
