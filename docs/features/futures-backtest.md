## 固定规则

两策略均用先前完整日线产生下一交易日开盘的目标方向，至少60根预热；当根开仓不使用当根收盘、最高、最低或成交量生成信号。

- **双均线20/60方向基准**：SMA20>SMA60目标做多，反向目标做空，相等目标空仓；预热后允许按现有状态首次入场，不要求等待新交叉。
- **唐奇安20/10收盘突破**：收盘超过之前20根最高价做多，低于之前20根最低价做空；持多时收盘跌破之前10根最低价退出，持空时反向退出；当根高低价不参与其自身突破阈值。不加仓。
- **共同保护**：开仓时使用此前14个真实波幅的简单均值（需15根价格）设置2ATR固定保护价，不追踪移动。跳空越过保护价按更差的开盘价退出；非跳空按保护价退出，再施加不利tick滑点和价位取整。保护退出当根不重新开仓。
- **反向与结束**：信号反向先平后开，分别收费；最后一根不新开仓，已有头寸在可撮合收盘退出。源无成交量、成交量为零或一字线时保守不撮合；结束无法成交时保留未平头寸，明确显示权益仍含浮盈亏。

源成交量只用于保守撮合可用性过滤，不参与开仓信号；日线不能还原真实成交队列和逐笔顺序。无止盈与分批加仓，避免同根止盈/止损的路径歧义。

## 合约、数据和参数

- 使用来源最近至多300根日线，当天及未来交易日保守排除；K线含源交易日，不把日线午夜当作真实成交时刻。预热在开始日期之前读取，回测开始时仍是空仓。
- 严禁回退到主力连续成交。不自动识别主力、不拼接月份、不计算跨合约换月盈亏。仅保留交割月份之前的样本；这只是研究截断，不是完整的最后交易日/自然人退出日规则。
- 报告显示实际可回测区间与预热数量。不同合约上市时间和覆盖不同，不能直接把其收益排名当作选型结论。
- 内置乘数/tick为可编辑规格预设，保证金与费率是独立研究输入。螺纹钢10吨/手、1元/吨参照[上期所业务细则](https://www.shfe.cn/regulation/exchangerules/productrules/202512/t20251231_829962.html)；黄金1000克/手、0.02元/克参照[黄金业务细则](https://www.shfe.cn/eng/services/Rules/SHFERules/202512/t20251231_829997.html)；原油1000桶/手、0.1元/桶参照[能源中心手册](https://www.ine.com.cn/upload/20240410/1712738949255.pdf)。其他规格预设及历史适用性仍应按具体合约核对，不以本页替代合约规则。
- 默认：10万元本金、每次1手、保证金比例15%、开仓占用不超过当时权益50%、每边每手3元、成交额费率0、平今费用倍数1、每边滑点1跳。**均为研究假设，不是历史实际券商/交易所费率或推荐仓位。**

## 账目和风险边界

毛盈亏按方向×价差×乘数×整数手计算。保证金不是买入成本；权益为已实现余额加浮盈亏。开、平手续费分别扣除；按成交额与固定每手费用可叠加，平今按源交易日判断。滑点进入成交价，不再从权益重复扣减；`slippage_cost`单独记录滑点及不利价位取整的估计影响。

开仓保证金超过权益占用上限，或保证金加开仓费用超过余额时拒单。收盘权益不足维持输入的固定保证金要求时停止新开仓，下一可撮合开盘退出；本模型不完整复现日内追保、强平与每日结算。跳空可导致负权益，不将其重置为零或补回本金。

最大回撤是**收盘权益**回撤，不是日内最大风险。没有足够交易时胜率/盈亏比保留未知；没有亏损样本时不生成无穷盈亏比。少于10笔完整交易会提示小样本。

比较表固定顺序展示两个策略：全段、手续费与配置滑点跳数翻倍，以及最后30%区间从相同本金空仓重跑。尾段只借用此前数据预热，不承接全段持仓；不自动调参，不将尾段称为严格样本外，不根据赢家切换任何账户策略。

## 导出与离线复跑

JSON导出包含参数、版本`cn-daily-v1`、样本SHA-256、源K线、曲线、逐笔、成本和限制。已归档的[真实样本报告](../reports/futures-backtest-2026-11-08/report.md)也可完全离线复跑：

```bash
python3 markets/us/dashboard/futures_backtest.py \
  --replay docs/reports/futures-backtest-2026-11-08/RB2701.json \
  --output /tmp/RB2701-replayed.json
```

数据与参数指纹用于复核输入；如未来修改算法，应提升版本并重新记录结果，不能只比较旧摘要。

## HTTP API

- `GET /api/futures/backtest`：仅查询规格预设、默认参数、策略名称，不创建任务。
- `POST /api/futures/backtest`：同源、JSON对象、最长4096字节；字段 `symbol/capital/lots/multiplier/tick_size/margin_rate/max_margin_fraction/fee_fixed/fee_rate/close_today_factor/slippage_ticks/start/end`。比率使用小数而非百分数，费率也为名义成交额的小数。
- `GET /api/futures/backtest?id=<id>`：任务`running/done/failed`；成功含`result`，失败含明确`error`。任务仅保留在当前进程，最多16个、同时2个；服务重启或过期ID返回404，需要重新显式运行。
- 缺少80根完整样本，或日期筛选后不足20根可回测日线时不输出比较表。市场账户和策略配置不在此接口权限范围内。
