# A股策略模拟与样本复盘

入口：[A股策略模拟](http://127.0.0.1:8766/a-paper)。模拟交易的市场选择、明日盯盘均有入口。

## 用户确认的流程

2026-11-09确认：用盘后候选，盘中符合原计划才买；买入后最早下一交易日，卖出也须满足策略条件。目的是积累证据、复盘胜率和收益、方便调整对照，不根据历史赢家自动切换运行策略。

独立100,000 CNY虚拟本金，默认暂停。默认每票含买入费用预算20,000元、最多3票、无杠杆、只做多。暂停且空仓后可改资金、费税、滑点和退出均线参数，保存不重置本金或历史，也不启用。已有期货、加密及美股合约账户独立保留。

## 计划与成交

2026-11-10起，新生成雷达使用分型v2：重返MA20确认、持续趋势回踩、放量突破分别检查趋势/量价并生成独立回踩计划。价格按整分处理、保留滑点空间，检查ATR保护与上方目标空间；大盘过滤和T+1纪律保留。旧名单与持仓不重写，今天不补造交易。[固定定义和首轮结果](../reports/a-share-setups-v2-2026-11-10/report.md)。

用户另行授权用昨日存档池重建新版计划、回放今天行情，已生成[11月10日上午独立回放](../reports/a-share-day-replay-2026-11-10/report.md)：13只股票、104条15分钟行情，覆盖至11:30。回放与前向账本分开，保留实际重建时间、未成交原因、CSV与原始输入；不将事后重建名单伪装为昨天实际生成。

- 只接「策略候选」，大盘过滤、行级市场条件和原计划plan_ready均通过；不把观察池升级为买入。
- 名单必须在信号日15:05以后、实际买入以前生成，信号日必须是最新指数序列中的前一交易日。盘后按启用状态每日准备一次候选；当日已有合格快照则复用，旧计划另行归档，防止次日页面刷新把历史名单改写为事后记录。
- 买入价须在原MA10至MA5回踩区间内，计入不利滑点后仍在计划内。观察到计划后等待严格晚于本机观察时间、启用/恢复时间的新源报价；同一信号日同一股票只买一次。
- 固定保存入场计划的止损和目标。T+1解锁后，当前报价触及止损/目标，或上一完整日线收盘跌破配置的MA10/MA20，才尝试卖出。当日触价但因T+1无法卖出，不在次日补造旧成交，次日重新核验。
- 沪深普通股票按100股整数倍买入，科创板至少200股，本实现仅取100股整数倍；排除ST、退市、北交所、ETF、CDR等。交易数量规则见[上交所现行股票交易规则](https://www.sse.com.cn/lawandrules/sselawsrules2025/stocks/exchange/c/c_20260424_10816482.shtml)及[深交所主板申报数量](https://investor.szse.cn/knowledge/t20230308_599142.html)。
- 仅09:30–11:30、13:00–14:57连续竞价采样；30秒内同股同源有效报价，买卖均需核验当日交易日序列；前收与新浪未复权完整日线对齐，使用源实际涨跌停价。买入按卖一向上取整并加不利tick，卖出按买一向下取整并减不利tick；价格超出计划/涨跌停或盘口缺失时等待。缺少深度、队列和完整交易日历，不保证触价可成交。
- 除权除息或前收口径变化时保留旧估值，停止该票撮合，需另行核验股数和成本；不自动调账或捏造盈亏。

## 账目与复盘

买入扣本金和费税，卖出回收成交额并扣费税，权益=现金+股票市值。佣金与最低佣金、双边过户费、卖方印花税分别记账，取分；滑点进入成交价，不重复扣费。默认佣金万3、最低5元、过户费万0.1、卖方印花税万5、每边1分滑点，均是可调整模拟输入。现行印花税信息可核对[上交所股票投资说明](https://one.sse.com.cn/onething/gptz/)，实际账户成本仍需自行核验。

完整逐笔保存在独立 `markets/us/dashboard/cache/a-share-paper.sqlite3`，页面显示最近100笔并汇总全历史。可导出完整前向记录（含入场计划和当时参数）；服务重启保留持仓和去重，清空待成交，不补造离线交易。暂停只停止新买入，旧仓仍按T+1和策略管理。

## 历史复盘与参数对照

页面提供独立复盘预算、最大持仓数和退出均线，费税沿用已保存账户参数；这些复盘设置不修改运行账户。点击后显式取样和运行，页面读取仅查询上次结果。比较基准、另一退出均线、成本翻倍及研究扩展候选口径。最后一项仅用于研究，不改前向候选来源。

逐日截断日线和指数，重算当时可见计划；以完整16根的15分钟交易日、每根开盘采样近似成交，使用同一账户引擎的计划、T+1、整手和费税。每日收盘只做估值，不强制平仓。缺少真实历史盘口，涨跌停按板块比例估算，且当前股票池回看有选择/幸存者偏差；不是严格样本外或历史真实订单回放。

展示累计收益、按实际日历跨度几何折算的月收益、逐月收益、最大收盘权益回撤、已平仓胜率、未平仓数、成本，以及大盘/候选/计划各层通过数量。零成交时胜率为未知。可导出JSON，保存输入指纹和逐笔；完整分钟/日线输入缓存在 `.cache/a-paper-research/sample-latest.json.gz`。

离线复跑（不联网、不改真实模拟账本）：

```bash
python3 markets/us/dashboard/a_paper_research.py \
  --sample .cache/a-paper-research/sample-latest.json.gz \
  --output /tmp/a-paper-replay.json
```

可加 `--config 参数.json` 覆盖预算、持仓和成本等本模拟允许的参数；报告逐个方案保留实际参数。首次研究结果见[44票样本报告](../reports/a-share-plan-2026-11-09/report.md)。

策略、入场与退出的进一步检验见[策略审计报告](../reports/a-share-strategy-audit-2026-11-09/report.md)。三个替代原型仅用于历史研究，未更换运行策略。

候选覆盖面及大盘过滤的独立对照见[11月10日过滤审计](../reports/a-share-market-filter-2026-11-10/report.md)，未更换运行候选或账户配置。

## API

- `GET /api/a-paper`、`GET /api/a-paper/export`：账户及完整前向导出，均不启用或扫描。
- `POST /api/a-paper/control`：布尔enabled，显式启用/暂停。
- `POST /api/a-paper/config`：暂停且空仓时保存允许的参数，拒绝本金重置。
- `POST /api/a-paper/research`：months 1–6、sample_size 1–46、可选config覆盖；独立后台任务，不改运行参数。
- `GET /api/a-paper/research[?id=...]`：上次结果/任务进度。

控制和配置按现有同源、JSON与长度约束处理。公开分钟接口有覆盖上限，最终复盘区间以报告实际日期为准。
