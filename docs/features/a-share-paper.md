# A股策略模拟与样本复盘

入口：[A股策略模拟](http://127.0.0.1:8766/a-paper)。模拟交易的市场选择、明日盯盘均有入口。

## 用户确认的流程

2026-11-09确认：用盘后候选，盘中符合原计划才买；买入后最早下一交易日，卖出也须满足策略条件。目的是积累证据、复盘胜率和收益、方便调整对照，不根据历史赢家自动切换运行策略。

独立100,000 CNY虚拟本金，默认暂停。默认每票含买入费用预算20,000元、最多3票、无杠杆、只做多。暂停且空仓后可改资金、费税、滑点和退出均线参数，保存不重置本金或历史，也不启用。已有期货、加密及美股合约账户独立保留。

用户另行授权用昨日存档池重建新版计划、回放今天行情，已生成[11月10日上午独立回放](../reports/a-share-day-replay-2026-11-10/report.md)：13只股票、104条15分钟行情，覆盖至11:30。回放与前向账本分开，保留实际重建时间、未成交原因、CSV与原始输入；不将事后重建名单伪装为昨天实际生成。

- 只接「策略候选」，大盘过滤、行级市场条件和原计划plan_ready均通过；不把观察池升级为买入。
- 名单必须在信号日15:05以后、实际买入以前生成，信号日必须是最新指数序列中的前一交易日。盘后按启用状态每日准备候选；当日已有合格快照则复用，扫描失败或日线未就绪时每15分钟重试，旧计划另行归档，防止次日页面刷新把历史名单改写为事后记录。
- 买入价须在原MA10至MA5回踩区间内，计入不利滑点后仍在计划内。观察到计划后等待严格晚于本机观察时间、启用/恢复时间的新源报价；同一信号日同一股票只买一次。
- 固定保存入场计划的止损和目标。T+1解锁后，当前报价触及止损/目标，或上一完整日线收盘跌破配置的MA10/MA20，才尝试卖出。当日触价但因T+1无法卖出，不在次日补造旧成交，次日重新核验。
- 沪深普通股票按100股整数倍买入，科创板至少200股，本实现仅取100股整数倍；排除ST、退市、北交所、ETF、CDR等。交易数量规则见[上交所现行股票交易规则](https://www.sse.com.cn/lawandrules/sselawsrules2025/stocks/exchange/c/c_20260424_10816482.shtml)及[深交所主板申报数量](https://investor.szse.cn/knowledge/t20230308_599142.html)。
- 仅09:30–11:30、13:00–14:57连续竞价采样；30秒内同股同源有效报价，买卖均需核验当日交易日序列；前收与新浪未复权完整日线对齐，使用源实际涨跌停价。买入按卖一向上取整并加不利tick，卖出按买一向下取整并减不利tick；价格超出计划/涨跌停或盘口缺失时等待。缺少深度、队列和完整交易日历，不保证触价可成交。
- 除权除息或前收口径变化时保留旧估值，停止该票撮合，需另行核验股数和成本；不自动调账或捏造盈亏。

## 账目与复盘

2026-11-12运行链路修正：盘后扫描核验个股日线必须到信号日；主源成功但滞后时回退到腾讯最新窗口未复权日线，使用整段同源历史，成交量从手统一为股。盘中撮合使用的前一交易日日线也校验新鲜度，失败不作为成功结果缓存一整天。扫描结果记录日线就绪数量及各排除原因；全部日线不可用时不得归档为有效空名单。当前仍为热榜前100只研究池，不代表扫描全市场。大盘过滤、买入计划、T+1与退出规则保持原定义。

页面分别显示账户启用状态、后台线程及心跳，缺失或超过两分钟未检查时显示待核实；请求失败显示连接中断。心跳正常仅说明后台有检查，不代表已满足交易条件。重启不会补造离线期间成交。

买入扣本金和费税，卖出回收成交额并扣费税，权益=现金+股票市值。佣金与最低佣金、双边过户费、卖方印花税分别记账，取分；滑点进入成交价，不重复扣费。默认佣金万3、最低5元、过户费万0.1、卖方印花税万5、每边1分滑点，均是可调整模拟输入。现行印花税信息可核对[上交所股票投资说明](https://one.sse.com.cn/onething/gptz/)，实际账户成本仍需自行核验。

完整逐笔保存在独立 `markets/us/dashboard/cache/a-share-paper.sqlite3`，页面显示最近100笔并汇总全历史。可导出完整前向记录（含入场计划和当时参数）；服务重启保留持仓和去重，清空待成交，不补造离线交易。暂停只停止新买入，旧仓仍按T+1和策略管理。

## 历史复盘与参数对照

页面提供独立复盘预算、最大持仓数和退出均线，费税沿用已保存账户参数；这些复盘设置不修改运行账户。点击后显式取样和运行，页面读取仅查询上次结果。比较基准、另一退出均线、成本翻倍及研究扩展候选口径。最后一项仅用于研究，不改前向候选来源。

逐日截断日线和指数，重算当时可见计划；使用完整16根的15分钟交易日，收盘只观察/准备、随后开盘才尝试成交，沿用同一账户引擎的计划、T+1、整手和费税。每日收盘只做估值，不强制平仓。缺少真实历史盘口，涨跌停按板块比例估算，且当前股票池回看有选择/幸存者偏差；不是严格样本外或历史真实订单回放。

回放版本 `bar-close-observe-next-open-v2` 修复了只在开盘采样、又重复等待新报价造成的额外延迟。同分钟收盘与后续开盘用边界后1/2毫秒表示模型顺序，价格仍取实际K线数据并加滑点；这不是实际毫秒级报价，也没有验证真实延迟、盘口和区间内保护止损的执行。单日和多日回放共用适配。原历史结果保留，旧缓存显示需重跑，不能直接与新口径比较收益。收盘准备模式在前向腾讯账户上被拒绝。

展示累计收益、按实际日历跨度几何折算的月收益、逐月收益、最大收盘权益回撤、已平仓胜率、未平仓数、成本，以及大盘/候选/计划各层通过数量。零成交时胜率为未知。可导出JSON，保存输入指纹和逐笔；完整分钟/日线输入缓存在 `.cache/a-paper-research/sample-latest.json.gz`。

离线复跑（不联网、不改真实模拟账本）：

## 全市场选股与超跌反转研究（2026-11-12）

新增独立选股检查，采用信号日的证券名单，覆盖沪深主板、创业板与科创板，排除指数、基金及交易所代码不匹配项。逐票记录停牌、风险证券、日线缺失、流动性、超跌、收复和计划空间各层首个未通过原因；不能把行情失败计成没有机会。`scripts/screen_a_candidates.py`可重复生成报告与明日盯盘页的只读全市场观察区域，不写候选账户或成交记录。页面明确显示信号日期及未就绪数量，不将昨日名单冒充今天生成的新计划。

```bash
python3 scripts/fetch_a_universe.py --date 2026-11-11 \
  --output .cache/a-universe-2026-11-11.json
python3 scripts/screen_a_candidates.py \
  --universe .cache/a-universe-2026-11-11.json --signal-date 2026-11-11 \
  --output docs/reports/a-share-candidate-screen-2026-11-11 --fetch
```

证券名单入口使用`requirements-feeds.txt`中已有的可选BaoStock依赖；不需要天勤账号。选股报告需显式运行，网页被动读取最后完整快照，不会因打开页面发起5000只股票的网络扫描。

超跌反转v3以RSI2、相对MA5的ATR偏离及日内收复选股；等待完整15分钟反转与后续新报价，保留T+1，目标为昨晚冻结MA5，计划风险含费用不超过权益0.5%。买前还要通过同数量双倍成本下预计净空间为正的检查。它是待验证规则，`RELEASED=False`及`PAPER_TRIAL=False`；原持仓不迁移，新候选也不会直接触发模拟账户。

本次修正回放版本为`bar-close-observe-next-open-limits-v3`：涨停附近不假定可买、跌停附近不假定可卖，保留另一方向的报价；此前整体丢弃边界报价会推迟退出并虚增某些交易收益。没有真实盘口，仍是采样撮合假设。旧报告不覆盖，新版本结果见[复查结论](../reports/a-share-oversold-reversal-v3-limits-2026-11-12/verdict.md)：开发样本23笔、收益−2.11%、双倍成本−2.32%、最大收盘回撤4.59%，不满足发布门槛。选出候选与证明盈利是不同阶段。

## API

回踩计划修订`a-pullback-wait-v1`（2026-11-20）：昨日收盘偏离回踩中心超过5%仅提示等待，不再否决未来回踩计划。结构无效、盈亏比不足1.5等仍拒绝计划；盘中卖一报价及加滑点成交价必须同时在原计划区间内。`warnings`与`rejection_reasons`分别记录等待提醒与否决原因，`chase_risk`仍表示昨日收盘偏离风险。雷达与归档记录`plan_revision`，实际买入持仓的计划也保留该字段；API的`active_plan_revision`表示当前生成器修订，不代表旧归档已改写。新规则从后续盘后名单生效，实际成交仍需大盘允许、计划到价、账户资金及整手等检查。

2026-11-20增加未开仓诊断：`source_diagnostics`显示最新盘后模拟源的热榜覆盖数、量价确认数、计划合格数、被大盘过滤的合格计划数，以及买入区域和盈亏比未通过原因。计划原因可以重叠，例如同一只股票同时离回踩位过远且盈亏比不足，不能相加当作独立股票数量。全A走强研究雷达与网页模拟源仍独立，看到研究候选不等于它已进入执行名单；实际可执行计划以账户`plans`为准。

- `GET /api/a-paper`、`GET /api/a-paper/export`：账户及完整前向导出，均不启用或扫描。
- `POST /api/a-paper/control`：布尔enabled，显式启用/暂停。
- `POST /api/a-paper/config`：暂停且空仓时保存允许的参数，拒绝本金重置。
- `POST /api/a-paper/research`：months 1–6、sample_size 1–46、可选config覆盖；独立后台任务，不改运行参数。
- `GET /api/a-paper/research[?id=...]`：上次结果/任务进度。

控制和配置按现有同源、JSON与长度约束处理。公开分钟接口有覆盖上限，最终复盘区间以报告实际日期为准。
