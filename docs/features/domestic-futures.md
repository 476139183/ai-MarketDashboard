# 国内商品期货分析

入口：侧栏「期货分析」，默认完整工作台地址 `http://127.0.0.1:8766/futures`。轻量看板同样可用，端口依启动参数。不需要DSA、AI模型或交易所账户密钥。

可输入上述品种的3/4位月份代码，如 `RB2701`。接口接受代码不代表该合约一定已上市或仍有数据；源无报价、已到期或不可用会明确提示。金融期货、海外期货及其他商品暂未纳入。

## 行情与时间

- 来源：新浪财经公开期货接口，HTTP轮询；可用性、延迟和字段口径由来源决定。接口字段核对参考 [AKShare期货接口源码](https://github.com/akfamily/akshare/blob/main/akshare/futures/futures_zh_sina.py)，本项目直接读取公开JSON/JSONP，不执行来源JavaScript，也不新增AKShare依赖。
- 每组查询至少间隔30秒，后台最多4个采集任务，缓存最多64组。首次返回 `loading`，页面轮询状态；同组查询不会重复启动采集。
- 页面区分源报价时间与成功采集时间。超过120秒的报价显示「休市或延迟」，不依据周末或时刻猜测交易所节假日状态。访问失败保留旧快照并显示错误，不能视为持续实时行情。
- 源报价的日期、时钟按北京时间组合，不把采集时间替换为报价时间。涨跌幅以昨结算价计算，昨结算缺失时不伪造涨跌。
- 日线横轴是来源交易日，不能把午夜视为成交时刻；分钟线保留源周期结束时间，不跨午休、夜盘收市重新合成K线。
- 每个查询使用最近300根源K线，按时间去重；窗口内无效OHLC、负量仓或重复冲突会使该次采集失败。历史窗口之外的坏记录不阻断当前图表。

## 分析口径

分钟线在源结束时间过后60秒才参与指标；日线仅将日期早于当前北京时间日期的线视为完整。当天收盘后日线仍会保守排除至次日，避免在没有完整期货日历时错误确认夜盘归属。形成中K线保留在图上并标注，指标不会使用。

| 指标 | 口径 |
|---|---|
| 历史结构 | 至少60根完整K线；收盘价>SMA20>SMA60为偏强，反向为偏弱，其余为交错 |
| SMA20 / SMA60 | 最近20/60根完整收盘价的简单平均 |
| ATR14 | 最近14根完整线的真实波幅简单平均，需15根价格记录；不是Wilder平滑ATR |
| 支撑 / 压力 | 最近至多20根完整线的最低价 / 最高价，为历史区间参考 |
| 相对量能 | 最后完整线成交量 / 前20根完整线均量，缺量或分母为零时未知 |
| 持仓变化 | 最后与前一根完整线的持仓量差，缺值时未知；不能单独推断多空主动性 |

价格单位按商品展示，量与持仓为源口径的手数，不转换为名义资金。页面观察池展示源累计成交量，图表显示逐根成交量，两者不能混用。

主力连续是源提供的拼接序列，没有在本项目中做复权或换月修正，也不推断当前主力月份。换月价差会影响均线、ATR和区间参考；具体交易研究需查看对应月份合约，并单独核验交割、期限结构、流动性、成本和保证金规则。首版是历史技术统计，不提供已验证的交易策略、基本面预测或自动模拟交易。

## 接口

- `GET /api/futures`：`items` 为12个连续合约；含 `price`、`change_pct`、`volume`、`open_interest`、`quote_at`、`quote_fresh`、合约身份与单位。单合约失败可在行级 `error` 查看。
- `GET /api/futures/chart?symbol=RB0&period=day`：周期 `day/5/15/30/60`；返回 `candles`、`analysis`、`quote`、`quote_error`、合约身份与 `time_convention`。
- 共同字段：`status` 为 `loading/idle/error`，`stale` 表示旧数据，`fetched_at` 为成功采集完成的毫秒时间戳。首次加载可能没有业务数据；顶层 `error` 不能当成空结果忽略。非法代码和周期返回400。
