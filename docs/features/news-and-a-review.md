# 资讯工作区与A股市场复盘

## 使用入口

启动 `bash start-web.sh` 后打开：

- `/news`：A股、美股、数字资产和全球财经资讯，可按关键词、最近采集范围、市场和页码查询。
- `/a-review`：A股指数、市场广度、量能、涨跌幅分布、行业榜单、事实摘要、下次开盘观察及近期资讯。

页面组织参考 [Daily Stock Analysis](https://github.com/ZhuLinsen/daily_stock_analysis) 的市场复盘与 Intelligence 模块；本仓库自行实现网页与适配，不自动调用上游的AI复盘或消息推送。

## 资讯如何进入本地

配置服务端 `DSA_BASE_URL`，如需认证则设置 `DSA_SESSION_COOKIE`。启动脚本锁定的DSA版本提供 `/api/v1/intelligence`。新闻记录存入DSA自己的数据库。

1. 进入资讯页，添加需要的内置来源。
2. 点击「采集资讯」。采集在后台执行，同一时刻只运行一个任务，单个来源失败后继续处理其他来源。
3. 查看来源状态，按市场或关键词检索，点击标题访问原文。

读取页面只查询本地资讯池，不自动创建来源、抓取外部网页、调用模型或发通知。内置来源包括财联社热门／金十财经（NewsNow）、SEC官方新闻、MarketWatch RSS及CoinDesk RSS。模板可用性受外部网站与网络环境影响。SEC来源是监管机构新闻稿，不是完整公司申报或财报日历；目前没有完整财报、解锁或宏观事件日历。

DSA尚无独立crypto市场枚举，数字资产来源按 `market=global, scope_type=market, scope_value=crypto` 存储；看板映射为「数字资产」。关键词匹配标题／摘要，不承诺严格的公司或标的归因。

### 时间与可信度

「最近采集」依据DSA的 `fetched_at` 筛选，不是新闻发布日期范围。重复抓取可能更新采集时间；采集时间不能视为首次可知时间，也不能直接用于历史回测。发布时间未知时保留未知；无时区的时间明确注明，不推断为北京时间。复盘资讯与行情日期独立展示，不将近期标题自动认定为当日涨跌原因。

正文按纯文本转义；只保留HTTP(S)原文链接，不接受脚本协议或含用户名密码的URL。源URL与原始采集错误不传给浏览器，已知敏感查询参数被移除；认证信息只在服务端。

### DNS／代理排查

DSA会阻止内网、环回及保留地址。代理的Fake-IP模式如果把公开域名解析到 `198.18.0.0/15`，添加来源会失败，看板提示检查Fake-IP／DNS设置。应在用户自己的代理中让新闻源域名解析为真实公网地址，再重试添加与采集。不要关闭DSA的地址校验。

2026-11-08本机验收：资讯查询接口、任务接口与页面可用，但5个内置来源均在创建时被上述Fake-IP校验阻止，实际资讯池为空。新闻列表、分页与恶意文本的浏览器验收使用隔离的浏览器替代数据，未向真实资讯池写入测试新闻，未宣称已通过真实新闻采集验收。

## 复盘数据口径

| 数据 | 来源与计算 | 缺失处理 |
|---|---|---|
| 7个主要指数 | 腾讯：上证、深成、创业板、沪深300、科创50、中证1000、北证50 | 各项保留行情时间；不能取得则不造值 |
| 全A市场广度 | 东方财富分页快照，代码去重数与总数一致才汇总；只计价格有效且有涨跌幅的报价 | 覆盖不完整时不汇总，退回明确标注的上证样本（非全A） |
| 涨跌分布 | 完整快照的有效报价，按7个涨跌区间计数 | 部分快照不冒充全市场分布 |
| 成交额 | 完整全A快照且所有有效报价有金额时求和；否则使用上证与深成指数提供的沪深成交额 | 沪深口径明确不含北交所，不叠加其他指数以免重复统计；不能取得则为空 |
| 涨跌停 | 东方财富指定日期涨跌停池的 `tc`，要求返回 `qdate` 与行情日一致 | 不按统一10%阈值推算；0与未知分开 |
| 行业强弱 | 东方财富行业板块涨跌幅前5与后5 | 不是资金流向，不推断连续主线 |

全A分页快照不是同一瞬间的成交快照；停牌、缺失和无效报价不混入涨跌统计。成交额不等于资金净流入，没有历史对比时不判断放量或缩量。

行情日取指数来源时间的多数日期；采集时间单独展示。周末最新周五数据不会仅因周末而判为行情过期；较早采集时间另行提示。节假日尚未接交易所日历，日期不匹配时需人工核验。页面事实摘要使用确定性规则，不是AI预测。

2026-11-08实测：行情日2026-11-06，5927个代码完整覆盖，5575个有效报价，352个报价无效或缺失；上涨758／下跌4741／平76；沪深成交额16577.94亿元；涨停32／跌停15。数据只作为这次验收的快照，后续以来源刷新结果为准。

## 本地接口

| 方法 | 路径 | 说明 |
|---|---|---|
| GET | `/api/news?market=cn&q=芯片&days=7&page=1&page_size=20` | 市场all/cn/us/crypto/global/hk，最近采集1–30天，每页1–100条 |
| GET | `/api/news/sources` | 已配置来源的安全状态摘要 |
| POST | `/api/news/sources` | JSON `preset`：cn/us/global/macro/crypto；同名来源不重复创建 |
| POST | `/api/news/refresh` | 显式启动后台采集；返回202，运行时重复请求合并 |
| GET | `/api/news/refresh` | 查询任务状态、逐源结果与错误 |
| GET | `/api/a-review` | 读取结构化复盘；`refresh=1` 启动后台刷新 |

来源已存在但停用时不会自动启用，需在DSA维护来源状态。资讯工作区不是新闻源管理后台，当前未开放任意URL编辑、删除或开关接口。
