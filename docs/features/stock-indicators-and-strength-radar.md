# 个股指标与全市场走强雷达

## 页面

- `/research?symbol=300324`：A股及美股原股的日线指标、成交量、市场结构及MACD副图。
- `/a-radar`：「全市场走强雷达」读取独立研究名单，可按形态、名称／代码、匹配度、首现日期、近5日涨幅与相对成交量筛选及排序，每页20只。
- 「扫描全市场」显式采集完整证券快照及日线，后台执行并显示进度。打开页面只读，不发起AI分析或全市场联网扫描。扫描失败保留上次快照并显示错误。

## 指标

| 指标 | 参数与实现 |
|---|---|
| MA | 简单均线5／10／20／60，使用对应完整周期 |
| MACD | EMA12−EMA26为DIF；DEA为DIF的9期EMA；柱值为2×(DIF−DEA)，明确采用倍增柱口径 |
| EMA种子 | 首个完整周期的简单均值；DIF至少26根，DEA与柱至少34根 |
| RSI14 | 14个相邻收盘变化初始化，随后Wilder平滑；无涨无跌为50，只有上涨为100、只有下跌为0 |
| ATR14 | 14个完整真实波幅初始化，随后Wilder平滑，包含跳空影响 |
| BOLL | 20日均值±2倍总体标准差 |
| MA20乖离 | (收盘/MA20−1)×100% |
| 相对成交量 | 所选日线量/此前20根均量；不是软件的盘中量比 |

始终从完整已加载历史计算，再截取展示范围；光标移动时读对应日期，不带入后面的K线。缺少价格会切断指标热身，缺量不补零。切换标的清空旧值，行情失败时不显示旧标的指标。当天日线保守标注「形成中」，不能当成收盘确认；复权、单位和价格口径依来源，除权可能影响指标。

公式参考：[Fidelity MACD](https://www.fidelity.com/learning-center/trading-investing/technical-analysis/technical-indicator-guide/macd)、[Fidelity RSI](https://www.fidelity.com/learning-center/trading-investing/technical-analysis/technical-indicator-guide/rsi)。倍增MACD柱与本文EMA初始化为本项目明确选定的计算口径，可能与其他软件的历史长度、种子或柱尺度不同。

## A股形态（固定研究规则v2）

先排除名称风险、停牌／无有效成交量、非法或陈旧日线、流动性不足及执行不可核验的一字线。至少60根日线，估算20日均额不低于5000万元；不使用原热榜100股上限或100亿元流通市值门槛。

| 分型 | 条件摘要 |
|---|---|
| 底部修复（高风险） | MA20仍下降；MA5刚在近3根内上穿MA10，价格收复MA5，近3日上涨且至少2根收涨，量能与乖离在固定范围内。不能称已形成上升趋势 |
| 初步转强 | 价格站在MA20上方且MA20基本走平，短均线拐头，近3日温和上涨并接近10日平台，量能温和 |
| 连续走强 | MA5>MA10>MA20、MA20上升；近5日涨2%～12%，至少3根收涨，量能不极端；不要求再创20日新高 |
| 温和放量突破 | 收盘突破此前20日高点，涨幅、相对成交量及收盘位置通过固定检查 |
| 回踩再启动 | 中期已有涨幅，近期触及MA10附近后收复MA5，价格、量能和收盘位置确认 |

涨幅过大、MA20乖离过大或接近估算涨停时，不列为当前新机会。不同分型可同时命中，匹配度仅用于规则排序，不是上涨概率。具体固定阈值见 `markets/a/strength_radar.py`，不按股票代码设置白名单。

「今日匹配」与「信号后跟踪」分开：跟踪只收录最近5根完整日线曾命中、当前已不再符合或过热的股票；不混入今日命中数量。首现为当前规则在历史数据逐日截断的回看日期，不能视为当时已经实际发出提醒；限定最近20根日线窗口，不代表上市以来首次，不能从首次显示日期推断可成交。

## 日期、覆盖与账户边界

最近完整交易日先按北京时间15:05窗口取上界，再用指数实际行情日期核验。当前证券列表可能包含信号日之后的名单／名称变化，因此只称当前名单回看，不能冒充历史全市场成分回测。每只股票必须具有信号日日线，未就绪与未达形态分开统计；不把部分覆盖写成全市场完整覆盖。

新的研究名单使用 `execution_enabled=false`，没有交易计划字段，不被现有模拟账户消费。原热榜计划雷达、全A突破CLI研究、加密／美股／商品期货及各账本继续各自使用原规则。

## 接口与存储

- `GET /api/a-strength`：只读缓存、日期、覆盖、排除统计、今日匹配、历史跟踪及任务状态。
- `POST /api/a-strength`，JSON `{}`：显式扫描；同一进程只允许一个任务；拒绝账户控制字段和外站Origin。
- `.cache/a-strength-radar/<信号日>/`：按代码缓存未复权日线及当次证券快照。
- `.cache/a-strength-radar/reports/`：按信号日及规则版本归档研究名单；`latest.json`为当前快照。
