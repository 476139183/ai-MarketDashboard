# 国内商品期货雷达

入口：[本地期货雷达](http://127.0.0.1:8766/futures-radar)。使用现有 `start-web.sh` 启动，不依赖 DSA 或 AI 模型。

支持螺纹钢、黄金、白银、沪铜、沪铝、原油、燃料油、豆粕、豆油、棕榈油、玉米、铁矿石的主力连续。可按分类、历史结构筛选，按较昨结算涨跌幅、量比、持仓变化排序，点击品种进入对应合约和周期的期货分析。

- 周期：日线、5/15/30/60分钟。
- 偏强：最后完整K线收盘价 > SMA20 > SMA60；偏弱为相反关系，其他为交错。少于60根完整K线显示不足。
- 量比：最后完整K线成交量 / 之前20根完整K线平均成交量。
- 持仓变化：最后两根完整K线持仓量差值，单位为手；不推断资金流入或多空主动性。
- 报价时间与最后完整K线时间独立显示。源报价超过120秒显示休市或延迟；历史结构依然只是历史描述。
- 单品种读取失败单独标记，不阻断其他品种；整批缓存失败保留旧快照并显示错误和采集时间。初次采集异步进行，通常需要等待多个请求完成。

主力连续不是可直接交易的月份合约，换月可能产生跳空。本页用于观察，不生成开仓信号或修改模拟交易账户。

只读接口：`GET /api/futures/radar?period=day`，返回 `items`、`period`、`status`、`error`、`stale`、`fetched_at` 与 `source`。每品种包含报价字段、`analysis` 及独立的 `analysis_error`。首轮返回 `status=loading` 时继续轮询；缓存按30秒刷新，K线最多四路并发。
