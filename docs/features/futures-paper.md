# 国内商品期货前向模拟

入口：[期货模拟](http://127.0.0.1:8766/futures-paper)，也可从「模拟交易」合约类型选择「国内商品期货」，或从期货雷达/分析进入。

## 启用与账户

- 独立人民币虚拟本金100,000 CNY，默认暂停。选择支持品种的四位月份合约（如RB2701）、核对成本和保证金参数，保存后手动点击「启用期货自动模拟」。
- 单次使用一个月份合约、整数手、最多一个持仓；不使用RB0等主力连续成交，不自动寻找主力或换月。交割月份开始禁止新仓，已有仓位继续管理。这是保守边界，不等价于各合约完整最后交易日规则。
- 暂停且空仓才可修改合约/参数，保存不重置本金、资金、历史或其他市场账户。暂停只停止新开仓，已有仓位继续在有效日盘报价下管理。
- SQLite账本位于 `markets/us/dashboard/cache/futures-paper.sqlite3`；与OKX/Binance和美股合约账本独立。启用状态、持仓、费用和去重键持久化，服务重启清除待成交信号，恢复后等待新报价，不补造停机期间成交。

## 独立期货规则

用户于2026-11-09明确选择双均线20/60自动模拟。沿用期货回测中该固定日线基准：SMA20高于SMA60目标做多，低于目标做空，相等目标空仓。至少60根此前完整日线，使用同月份合约日线，不依据雷达的分钟周期改策略。

必须有源当日日线作为历史数据锚，排除当日形成中日线。观察到信号后，等待源报价时间严格晚于首次源报价、本机观察时间和启用/恢复时间的新报价。每个合约、策略、完整日线及方向只开一次；保护退出后不重复追同一信号。反向先平仓，后续再经过信号观察/新报价等待才能开反向仓。

开仓以此前14个真实波幅的简单均值设置固定2ATR保护价，不追踪、不设固定止盈。退出优先检查保证金不足、固定保护价和日线方向改变；信号数据失效不执行方向退出，但仍可用有效新报价执行既有保护价或保证金退出。

## 撮合、费用和保证金

首版只支持北京时间日盘09:00–10:15、10:30–11:30、13:30–15:00内的30秒内新鲜报价，还需源日期相符、成交量有效及同合约/来源检查。时间参考[上期所交易时间](https://www.shfe.com.cn/services/calenderandholidays/tradinghours/)和[大商所交易说明](https://www.dce.com.cn/dceg/file/2025-05-29/1748480876704ff80808197162e7128701971994e0a01313.pdf)。时间窗不替代完整交易日历；休市报价不能作为新成交。

夜盘、休市、断网和停机期间不补造成交；已有仓位的退出也只在有效日盘新报价下处理。本页不是夜盘风控工具。

使用源最新价加每边不利tick滑点，买入向上取整、卖出向下取整；不是买卖盘口撮合保证。价差×方向×手数×合约乘数计算毛盈亏。固定每手费与成交额费可叠加，开平分别收取，平今按日盘源日期应用费用倍数。滑点进入成交价，不重复扣余额。

账户余额=本金+已平毛盈亏−全部已收手续费；权益=余额+浮盈亏；占用保证金=源报价×合约乘数×手数×固定保证金比例；可用资金=权益−保证金。开仓同时计入当次手续费和不利滑点造成的浮亏，再检查占用上限，保证金不是买入成本。权益/保证金不足时按有效新报价退出，暂停开仓，保留可能出现的负权益。

默认每次1手、保证金15%、开仓占用不超过权益50%、每边每手3元、成交额费率0、平今倍数1、每边1跳滑点；均为模拟假设，不代表实际费率或仓位建议。乘数与tick沿用已有期货品种预设。

未完整重建夜盘、交易日历、逐笔和涨跌停队列、每日结算、交割和真实强平。采样可能错过触价，行情失败保留上次估值并标出过期；这项基准仍待独立验证，不自动迁移加密策略或修改现有模拟持仓。

## 本地接口

- `GET /api/futures/paper`：只读账户及规格预设，不启用账户或发起源采集。
- `POST /api/futures/paper/control`：JSON `{"enabled": true/false}`，显式启用或暂停新仓。
- `POST /api/futures/paper/config`：暂停且空仓时保存 `symbol/strategy/lots/multiplier/tick_size/margin_rate/max_margin_fraction/fee_fixed/fee_rate/close_today_factor/slippage_ticks`；比例使用小数，strategy仅允许sma，不接受本金重置。

控制/配置遵循现有同源与JSON长度检查。后台在本地服务运行时每轮等待10秒；源请求耗时另计。持仓、最新100条平仓记录和全历史汇总分别显示。
