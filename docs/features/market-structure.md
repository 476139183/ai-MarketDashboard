# 多市场结构与价格区域标注

A股、美股日线使用“行情研究”的日K图；美股分钟线使用“美股雷达”；加密货币和股票永续使用“合约雷达”展开后的K线。A股明日盯盘已有“研究”入口，可直接打开对应股票。三个入口共用前端结构算法与图表图层。

## 图上标记

| 标记 | 含义 |
|---|---|
| H / L | 当前输入窗口内首个已确认高点 / 低点 |
| HH / LH | 相对上一确认高点，更高 / 更低的高点 |
| HL / LL | 相对上一确认低点，更高 / 更低的低点 |
| EQH / EQL | 两个分别确认的摆动高点 / 低点价格相等 |

## 确认和时序

默认左右各5根确认一个严格局部高低点，可切换为3/5/10根。左右窗口内存在同价平台时，不制造严格局部极值。高低点标签画在发生K线，但附“确+5”等延迟说明；状态栏分别给出发生K线和确认K线。时间戳标识该根K线的起始时间，事件只能在确认K线收盘后使用。

只以收盘突破确认BOS/CHoCH，上影或下影越界本身不产生突破事件。未收盘K线仍显示在原行情图中，但不确认拐点、创建缺口或改变结构方向。当日日K采用保守处理：按A股上海日期或美股纽约日期排除当日日K，等待后续日期的数据再参与结构计算。仅有分时价格采样、没有真实OHLC时明确暂停结构标注。

结构以当前取得的历史窗口为上下文。重新加载或滚动数据窗口的左边界可能改变最早几个标签的初始化；不能把图层当成跨窗口持久化的交易信号数据库。图层本身不发送订单，不改变已有策略或模拟交易撮合。

## 区域更新

当前范围来自最近确认的高点与低点；边界交叉或不足时不画范围。FVG在第三根K线收盘后才创建，从创建K线开始绘制；之后已收盘K线部分回补时缩小，完全回补后移除。图层显示当前仍有效区域，不将今天看到的区域回填为过去已经可用的交易条件。

为控制拥挤，图上最多显示最近36个高低点、20个结构事件和每方向3个有效缺口；相邻区域文字避让，图层可分别关闭。区域不改变原有价格自动缩放，也不覆盖成交量面板。

## 边界与参考

这些是OHLC价格形态，不代表真实机构订单、止损挂单或主动买卖资金。股票复权口径、拆股、隔夜跳空和数据缺口都可能影响图形，标注没有独立证明收益优势。订单块、多空比和逐笔成交密集度不在本次图层范围。

展示思路参考[SMC Marks](https://github.com/kxngHADES/SMC-Marking)，其Pine脚本标注MPL-2.0；本次采用通用价格结构口径实现前端图层，没有直接嵌入Pine脚本。绘图扩展使用[Lightweight Charts 5.2系列原生图元接口](https://tradingview.github.io/lightweight-charts/docs/plugins/series-primitives)，保留原图表库许可与署名。有关延后确认和历史回画的解释，可参阅[TradingView重绘说明](https://www.tradingview.com/pine-script-docs/concepts/repainting/)。
