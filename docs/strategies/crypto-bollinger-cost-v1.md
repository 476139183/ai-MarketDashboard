# 编号6：布林带震荡回归＋成本空间过滤

策略标识：`crypto-bollinger-cost-v1`。适用于 BTC、ETH、SOL 的 OKX USDT 线性永续历史研究。实现仅依赖 Python 3.10+ 标准库；不会连接账户、读取密钥或向交易所发单，也不会替换看板中的线上模拟策略。

## 固定规则

- **信号周期**：只使用已闭合4h OHLC；布林带为20根收盘价的简单均值±2倍总体标准差。
- **震荡入场**：ADX14<20。前一收盘在下轨之外、本根收盘回到下轨内时触发多头；上轨对称触发空头。ADX和ATR均用Wilder平滑。
- **编号6过滤**：信号时 `方向×(中轨/收盘价−1)≥0.0066`，即到中轨的有利空间至少为预估往返成本的3倍。静态成本代理为 `2×(0.06%手续费+0.05%不利滑点)=0.22%`。它不是未来净利润保证，不包含事前未知资金费和下一根开盘跳动；浮点阈值仅容忍约1e-15舍入误差。
- **退出**：多头收盘回到中轨或更高、空头回到中轨或更低，或ADX≥25时撤销持仓状态；在后续5m开盘执行。过滤只限制新增入场，不改变持仓退出状态。
- **保护止损**：开仓时 `d=clip(2×ATR20/信号收盘,0.5%,4%)`，固定在成交价的方向反侧；无固定止盈。不设置事后最高价止盈，不因止损自动制造新入场触发。
- **执行时序**：4h信号先观察，再至少等待一个5m开盘；每个币每个4h方向只执行一次。跳空越止损按开盘处理；5m根内触及止损按止损价加不利滑点处理。不能提前用本根高低价释放开仓额度。
- **账户**：10,000 USDT初始权益、10x杠杆，每笔保证金目标/上限为开仓前净值20%，最多三币各一仓。新增后总保证金不得超过计入即时费用/滑点影响后的净值60%；额度不足裁小新仓，之后不强制再平衡。
- **成本**：每边手续费0.06%，每边不利滑点0.05%；按实际持仓、结算时5m标记开盘和历史已结算费率计资金费，直接改变对应逐仓保证金。

## 运行

仓库根目录执行：

```bash
python3 markets/us/backtest/crypto_bollinger_cost.py \
  --bundle /path/to/normalized-okx-bundle.json \
  --output /tmp/crypto-bollinger-cost-result.json

python3 -m unittest discover -s markets/us/backtest -p 'test_crypto_bollinger_cost.py'
python3 -m unittest discover -s markets/us/backtest -p 'test_crypto_replay_engine.py'
```

可用 `--start` / `--end` 指定UTC Unix毫秒区间，须对齐4h并处于输入覆盖内。每次回放从初始本金空仓开始。输出包含规则、输入文件SHA256、收益/回撤、手续费/资金费、每笔交易及4h抽样权益；回撤仍按完整5m标记收盘计算。

本机保存了本轮冻结数据，可直接复现：

```bash
python3 markets/us/backtest/crypto_bollinger_cost.py \
  --bundle markets/us/.cache/crypto-ema-replay/experiments-bundle-1786089600000-1794038400000.json \
  --output /tmp/strategy06-full.json
```

缓存原始行情不随此策略提交。新克隆须自行准备下述数据；交易所历史保留期、历史规格和数据修订可能导致重新采集无法获得相同样本，不能承诺当前公开接口仍提供全部冻结数据。

## 输入格式与验证

JSON顶层为 `{"start": UTC毫秒, "end": UTC毫秒, "data": {"BTC": {...}, "ETH": {...}, "SOL": {...}}}`，每币字段：

| 字段 | 格式与要求 |
|---|---|
| `fast` | 连续、已闭合5m成交K线；每根包含整数`t`及数字`o,h,l,c`，可附基础币量`v` |
| `slow` | 连续、已闭合4h成交K线，同上；区间前至少60根预热；本次冻结数据提供70天预热 |
| `marks` | 完整同区间5m历史标记价格OHLC，不允许回退到成交价代替 |
| `funding` | `{"complete": true, "rates": {"结算UTC毫秒": 已结算费率}}`，结算覆盖需连续，间隔不超过8小时 |
| `spec` | 正数`ctVal,lotSz,minSz`，可用数字字符串；可附`mmr`及`tier_maxSz`；未提供`mmr`时仅按0.4%做风险筛查 |

程序验证时间连续、无重复、价格合法、5m聚合与4h一致、标记价和资金费覆盖。仅支持上述三币的子集；缺行情或出现强平先后无法确定的路径时终止，不输出伪完整收益。缺少历史维持保证金档位和根内成交路径时，该筛查不等于真实交易所强平模拟。

## 冻结回放结果与证据边界

数据截止北京时间 **2026-11-07 16:00**，并非随后实时更新的业绩。此版从看过原交易后的六项有限调整中提出，属于事后研究候选。它的最低开发段收益与原版相同，不能称为通过独立未见数据验证的最佳策略。

| 独立账户窗口 | 净收益 | 最大回撤 | 平仓次数 |
|---|---:|---:|---:|
| 完整三个月：8/7—11/7 | +20.01% | 15.96% | 19 |
| 开发1：8/7—9/7 | +3.01% | 15.96% | 5 |
| 开发2：9/7—10/7 | +14.15% | 10.94% | 11 |
| 最近月：10/7—11/7 | +2.06% | 9.05% | 3 |

手续费和滑点同时翻倍重新回放，三个月收益为+10.98%，最近月+0.73%。最近月三笔全来自SOL，BTC/ETH没有交易。样本很少，且三个月结果与分段账户存在复利路径差异，分段收益不能相加。

独立实现与本地封存版本核对：三币全部信号、持仓状态及入场风险参数相同；四个窗口的每笔交易、费用、资金费、收益和回撤完全一致。公开的[结果快照](crypto-bollinger-cost-v1-results.json)和[交易明细](crypto-bollinger-cost-v1-trades.csv)仅包含编号6；全段与最近月存在重叠，CSV共22行不是22次独立交易。

OHLC不包含盘口、部分成交和根内先后。行情规格采用冻结时元数据，标记收盘回撤不覆盖全部盘中尖峰。该版本保留作模拟研究，尚不能据此认定稳定盈利。

规则解释可参考[Bollinger本人说明](https://www.bollingerbands.com/bollinger-band-rules)；数据字段来源为[OKX官方API文档](https://www.okx.com/docs-v5/en/)。0.66%过滤、ADX门槛与本项目的杠杆配置是本项目实验规则，并非上述来源承诺的盈利参数。
