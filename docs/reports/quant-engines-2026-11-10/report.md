## 先验证引擎与时序

合成样本验证RQAlpha实际买卖、A股当日买入不可卖、期货乘数/滑点/费用，并验证单次触价后离开区间不会替代连续有效计划报价。资金与逐笔/持仓估值对账失败时任务直接失败，不生成成功结果。

A股扩展候选曾因适配器把“连续区间内报价”误作“任意两条报价”而产生多余交易，已修正并加入回归。最终同一样本下独立框架与旧引擎均为5笔已平仓、0胜，账户权益98,188.84元、费用96.16元、收益−1.81116%，完成成交语义与账目交叉核对。

## 复现与交付

```bash
bash scripts/setup-quant.sh

```

全部30组配置、数据/代码指纹、成交、权益曲线和拒单摘要见[summary.json](summary.json)及其链接文件。A股原始样本指纹为`3dda69b252e73994a5283e4c45c4c3a023884c64d375b9f6e30a19704e703fe0`；期货分别验证已有月份归档的原始样本指纹。未做参数网格搜索或同样本择优晋升。

网页入口为`/quant-research`，显式点击才启动隔离子进程，可导出完整报告；缺依赖、缺本地数据、天勤无账号、错误参数和运行失败分别显示。现有A股与期货模拟页均提供入口。

当前结论是完成了独立引擎、成本/账目交叉验证与风险仓位研究能力，尚未验证出可直接替换的稳定盈利策略。数据池选择偏差、历史证券状态、复权/公司行动、盘口、夜盘、历史保证金和换月等仍需独立完善。完整使用与许可边界见[功能说明](../../features/quant-research.md)。
