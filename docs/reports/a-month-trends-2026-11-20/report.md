# 最近一个月A股趋势归纳与入场规则研究

窗口：2026-10-20至2026-11-19，共23个交易日。按用户要求先找出实际走出趋势的股票，再检查当时可识别的结构，调整雷达与研究入场规则。结论：持续趋势跟踪的覆盖从114/151提高到146/151；新的确认入场仍只有56/151符合次日开盘代理区间，组合研究亏损，尚未实现“大部分趋势票的有效入场”。

## 全量范围及趋势定义

新浪当前证券快照5579只，名称显示风险警示或退市的197只排除，5382只全部取得日线，无请求失败。扫描范围包括沪市主板1632、深市主板1420、创业板1371、科创板606、北交所353只。19只缺月初基准或期末收盘，剩余5363只可计算月度价格变化；这与雷达要求至少60根日线的有效覆盖口径不同，最新雷达有效5341、未就绪41只。

在运行结果分析前固定两种分组：

- 持续趋势：月涨幅≥10%、窗口内至少60%的日线收盘不低于当时MA20、末日MA20高于5个交易日前MA20，共151只。
- 月涨幅组：≥15%共118只，其中≥30%为25只。它与持续趋势组有重叠，不相加。

这些是事后评价标签，不输入信号计算、排序或组合订单。证券名单是当前快照，不能声称还原当时全部上市、退市、ST状态。未复权日线不完整处理除权分红，因此本文涨幅是源价格变化，不是股东总回报。

完整151只见[trend-stocks.csv](trend-stocks.csv)，包括原形态首现、结构首现及研究区间入场代理，缺失值留空，绝不补成理想买点。[results.json](results.json)保留全部汇总及组合逐笔记录；没有选择只展示成功个股。

## 从走势归纳出的共性和漏选原因

1. **持续上涨不等于每天都有新突破。** MA5>MA10>MA20且MA20上行的结构可以持续存在，原五形态却只认狭窄的当日形态。旧信号超过5根后会从跟踪中消失。
2. **固定过热门槛会把趋势和入场混为一谈。** 九阳股份在本窗口所有观察日都被过热门槛拦截，窗口价格上涨约66.99%。它适合保留结构跟踪，但不能据期末涨幅倒推每一天都能追买。奥雅股份约涨141.30%，也有多日过热及初期流动性不足，没有合格入场不能事后补造。
3. **大盘过滤确实阻止了全部旧计划。** 23个对应信号日沪深300均未站上MA20，持续趋势组124只曾有结构合格计划，却没有一只通过指数过滤。个股与指数有分化，但不能据个别上涨股票证明取消过滤能改善整个组合；本次新组合实际上亏损。
4. **底部修复与持续趋势应分开。** 原底部修复首个信号的完整5日样本1820个，正收益比例23.02%，同日期对照31.01%；对覆盖有帮助，不能直接升级为趋势买入。
5. **确认与价格仍是主要难点。** 新结构能跟踪大多数趋势票，加入缩量回踩收复、波动距离和次日区间条件后，覆盖明显下降。这是需要继续验证的约束，不通过查看期末赢家反复放松门槛。

上述“原因”指可核验的量价结构及程序过滤，未采集逐票同期公告、财务变化或真实资金流，不将它们当成基本面因果解释。

## 原五形态的完整对照

每只股票只取本月第一个有效研究信号，最早按下一交易日开盘计算价格代理；后续窗口不完整时不计5日结果。排除一字线、无成交量及近涨停开盘的样本，不假定可以排队成交。5日标签按第5个持有交易日收盘计算，每边0.15%成本、每边1分钱不利滑点；这不是模拟账户收益。

| 指标 | 原五形态 |
|---|---:|
| 持续趋势候选覆盖 | 114/151，75.50% |
| 较早价格代理覆盖 | 58/151，38.41% |
| 月涨≥15%组覆盖 | 77/118，65.25% |
| 月涨≥30%组覆盖 | 12/25，48.00% |
| 首个信号完整5日样本 | 2673 |
| 5日正收益比例 / 同日期对照 | 27.39% / 32.50% |
| 5日平均变化 / 同日期对照 | −4.17% / −3.13% |

“较早”固定定义为入场代理价格不超过月初基准价格加全月价格增量的30%，仅是事后评价信号是否出现得足够早，不用于决定当时的入场。候选覆盖不能当作实际成交覆盖或盈利概率。

## 已实现的策略调整

版本：`a-strength-research-v3`，新增`a-trend-structure-v1`，对全部证券统一执行，不按用户提到的代码设置例外。

- **趋势持续跟踪**：MA5>MA10>MA20、MA20上行、收盘高于MA20、20日涨幅>2%，沿用名称、日线、流动性及跳变核验。当前趋势还在时，不要求最近5天必须命中过旧形态；单独记录结构首现，不伪造旧形态命中日期。
- **缩量回踩收复**：前两根附近曾触及MA5+0.5ATR范围，触及日量不超过此前5根均量的90%；本根收复前日高点、收阳且收在日内上方，量能恢复到固定范围。
- **突破确认**：收盘突破此前20日高点，量能为此前20根均量1.2～3倍且收盘位置确认。两类均要求距MA5不超过1.5ATR；一字线、近涨停保留等待状态。
- **研究区间与退出**：在信号收盘附近按ATR冻结区间；本规则ATR是最近14个真实波幅的简单均值。保护参考结合最近3根低点、MA10与0.25ATR，计划上沿至保护参考风险不超过8%；不预设小止盈，记录MA10失守后的后续报价退出设想。所有字段明确`execution_enabled=false`，不接入现有账户订单。

页面将“旧形态未命中”和“结构首现”分开；趋势跟踪不计入今日五形态匹配数量。研究入场确认时显示区间和保护参考，未确认则继续跟踪。

| 持续趋势组 | 数量 | 比例 |
|---|---:|---:|
| 新结构曾覆盖 | 146/151 | 96.69% |
| 新入场形态曾确认 | 60/151 | 39.74% |
| 次日开盘代理落在冻结区间 | 56/151 | 37.09% |
| 其中满足较早价格评价 | 16/151 | 10.60% |
| 其中至期末仍有≥5%空间 | 27/151 | 17.88% |

96.69%是结构跟踪覆盖，绝不是已取得96.69%的有效入场。原候选与新冻结入场条件口径不同，不能只看两列覆盖变化评价收益改进。

## 新入场与组合检验

全部股票的新研究区间，首个完整5日样本368个，正收益比例37.23%，同日期对照38.02%；平均变化−2.11%，对照−2.05%。前半段正收益42.29%，后半段31.14%，后半段仍弱于对照33.82%。本月汇总已经看过，后半段只是固定诊断分段，不是严格未见样本外验证。

另做独立日线组合近似回放：初始10万元、最多3仓、单票最多1万元、含成本计划风险每笔0.25%权益，按信号日20日涨幅、成交额和代码固定排序；整数股数与科创板最小200股，北交所暂不接入组合。T+1后才允许卖出，跳空先按开盘保护、再检查前日MA10失守、最后检查日线低点触及保护。期末持仓只估值，不强卖。

| 口径 | 收益 | 最大收盘回撤 | 已平仓 | 盈利 | 期末持仓 |
|---|---:|---:|---:|---:|---:|
| 新方案日线近似组合 | −1.55% | 1.91% | 13 | 2 | 3 |
| 同成交数量与时刻，成本翻倍 | −1.81% | 未重建 | 13 | 2 | 3 |
| 成本翻倍并重新计算风险股数 | −1.52% | 1.86% | 13 | 2 | 3 |

第三组与固定成交压力组不同，股数因成本和风险预算变化，亏损略少不能解释成成本变高更有利。逐笔与拒绝原因完整保留；最多3仓产生647次候选拒绝，说明“发现大多数趋势票”也不等于账户可以同时持有它们。

[trade-audit.csv](trade-audit.csv)核对13笔平仓的信号先后、T+1、入场区间、整手和模型退出触发，均符合这套近似模型。检查通过不代表市场预测正确，也不证明有真实盘口可成交。

日线模型不能还原盘口、逐笔、盘中路径、涨跌停队列及停牌；次日整根一字线与成交量过滤是保守可执行性代理，不能用于声称实时开盘已知整天的状态。保护价触发和当日低点成交是模型假设，不能当作真实成交证据。未复权数据及当前名单偏差继续存在。

## 用户质疑后的收益复核与归因

原来的−1.55%不是“只交易151只最终上涨股票”的组合；它是新规则在全市场当时可见信号中实际选股的近似回放。151只是月底已知的研究分组，不能在真实验证中用它提前剔除后来未上涨的股票。此前文字未充分区分两种股票集合，此处明确更正。

独立使用Decimal重建全部买卖现金流：期末现金89086.09元，持仓标记市值9363.00元，权益98449.09元，与原结果完全相符。已平仓净亏1545.82元、未平仓净浮亏5.09元，合计1550.91元。总费税174.91元，主要亏损不是手续费重复扣除。

实际累计买入16只，其中只有5只属于事后151只趋势组。其余11只已平仓交易合计净亏1369.72元；趋势组内两笔已平仓合计净亏176.10元，另三笔期末持仓净浮亏5.09元。这里“组外”表示不满足最终趋势定义，不代表11笔全都亏损。[loss-attribution.json](loss-attribution.json)逐只记录月度涨幅、实际入场、退出及期末价格。

许继电气是趋势股仍亏损的实际例子：全月价格上涨13.21%，组合10月23日以22.60买入，保护参考21.81，10月30日跳空开21.43，按不利滑点21.42退出，亏248.23元；期末价格25.79。威高血净全月上涨16.46%，组合直到11月16日才以34.89买入，期末34.38，仍有浮亏。月初到月末上涨不等于任意时点买入后的持仓盈利。

为了诊断退出方式，另外固定入场生成规则、排序、资金和仓位限制，做5组退出对照；只改变退出均线、初始保护模型或确认根数，不以结果选择赢家。2ATR保护使用信号日已知的14个真实波幅简单均值，风险股数随保护距离重算。单独加入“月底151只白名单”对照，仅帮助区分选股与退出问题，它明确包含未来信息，不能作为策略收益或发布依据。

对照保留在[exit-audit.json](exit-audit.json)。退出改变后，占用仓位、后续成交和风险股数也可能变化，因此该表是同一组合框架内的规则对照，不是固定每笔成交的单项价格替换。默认分支已核对仍精确复现−1.55091%，未改写原结果。未来白名单的盈利不能用来证明真实选股策略有效。

归因结论：金额计算没有发现错误，当前信号会买入未延续的股票；在最终上涨的股票中，入场偏晚和中途退出也会造成亏损。仅放宽退出并不能让本月全市场组合转正，不能把差异全部归因于“止损太紧”。新入场模型仍保持研究状态，不据此直接修改运行账户。

## 保留与后续边界

持续趋势跟踪改进已保留并更新本地雷达名单，自动买入入口因本次检验未通过继续关闭。原A股账户规则、配置、资金、持仓及历史保留，没有把过去的理想入场导入前向账本，也没有启用此前失败的强势延续、回踩收复或超跌反转通道。

若继续研究，优先用新的日期验证本次冻结的条件与退出模型，补充分钟级真实可执行性及市场风险分层；不继续在这一个月上寻找能解释最多赢家的阈值。当前结论没有达到大部分有效入场的目标，完整失败结果作为下一轮对照保留。
