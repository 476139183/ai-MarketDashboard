## 期货：日线接口口径与模拟器要求不一致

RB2701盘中报价有效，但新浪日线接口最后一根是11月19日完整日线。旧模拟器要求最后一根必须是今天的日线，因此持续报“等待源当日日线，不能用旧日线补造新信号”。接口只发布已收盘日线时，这个要求会阻止所有新信号。

修复后按核验过的日盘交易日历检查上一交易日完整日线，不要求额外的当日形成中日线；不使用当日收盘价，也不拼造今天的K线。历史滞后、未来日期、历史不足、错误月份合约或过期报价仍拒绝新仓，已有持仓仍按有效新报价检查保护条件。

启用状态和配置核对一致，没有重置本金、导入历史持仓或补造停机成交。本次只证明执行链路恢复，不证明双均线策略盈利。

交易日历依据[上期所2026年休市公告](https://www.shfe.cn/publicnotice/notice/202512/t20251217_829805.html)、[能源中心休市安排](https://www.ine.cn/services/calenderandholidays/holiday/)及大商所发〔2025〕437号。当前仅核验2026年日盘；未来年份未核验时暂停新信号，仍保留既有仓位的有效报价保护检查。夜盘、临时休市及完整结算模型不在本次修复范围。

## A股：研究雷达与实际执行候选不同

11月19日盘后模拟源仍是热榜100只，不是全A走强研究雷达。52只被初筛排除，其中51只因当前流通市值低于100亿元，1只因最近交易日日线不完整。

## 逐笔执行核对与限制

[机器可读结果及逐笔检查](results.json)保留9组汇总、输入文件SHA256、计划/成交诊断和已平仓检查。重复方案中的同一笔不能重复当作独立交易样本。核对内容包括信号早于入场、T+1、成交价在计划内、股数规则以及买卖费税求和；通过检查表示符合回放执行模型，不表示每笔买卖是正确的市场预测。

所有期末持仓只估值，未假装卖出；收益包含浮盈亏，未来退出成本未扣除。双倍成本组固定原成交时刻与数量，仅重算费税和滑点，不是重新撮合。没有真实历史盘口，15分钟开盘价无法证明该数量实际可成交；历史涨跌停、停牌、除权、ST及证券范围仍不完整，最大回撤只按日末权益计算。旧研究数据已经被多次检验，禁止按本表挑选最好一格作为新的默认策略。

import gzip, json, sys
sys.path[:0] = ['markets/us/dashboard', 'markets/a', '.']
import a_paper_research as R

with gzip.open('.cache/paper-opening-audit/recent/sample.json.gz', 'rt') as f:
    sample = json.load(f)
for name, market_filter, expanded in [
    ('baseline', True, False),
    ('no_market_veto', False, False),
    ('broader_pool_no_veto', False, True),
]:
    data = dict(sample)
    if expanded:
        data.pop('legacy_eligible', None)
    result = R.replay(data, R.P.DEFAULTS, radar_factory=lambda s, d:
                      R.setups_radar(s, d, market_filter=market_filter))
    print(name, result['summary'], R.fixed_execution_stress(result))
