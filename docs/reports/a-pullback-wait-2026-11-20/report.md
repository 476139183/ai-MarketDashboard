# A股回踩计划判定调整

用户于2026-11-20核对候选后授权调整通过判定。计划修订：`a-pullback-wait-v1`，量价分型仍为`a-setups-v2`。本次没有新增或启用其他市场及研究买入通道。

## 修改

旧规则用信号日收盘距离回踩中心超过5%否决整个计划，即使未来买入价仍在原回踩区间。现在把该条件改为`warnings`等待提醒，保留`chase_risk=True`描述当前偏离；`rejection_reasons`只包含结构无效、区间不足及毛盈亏比不足1.5等否决原因。

买入仍要求盘中卖一价与包含滑点的模拟成交价均落在原计划区间，首次观察后等待后续新报价；不在信号日收盘价追买。原止损目标、大盘过滤、T+1、账户资金及整手规则继续生效。

`plan_revision`进入雷达、候选归档以及实际成交保存的计划。后台盘后检测修订变化再生成当日名单；不在盘中重算并替换昨日归档，不重置账户或修改持仓。API的`active_plan_revision`是当前生成器版本，不能用它声称旧归档已经采用新规则。服务重载后已核对A股和期货账户启用状态、配置、持仓数保持。
