# 全市场选股单变量实验

用户再次明确：不固定60股，保留全量每日扫描；当前重点是选股问题。本轮保留原MA5/MA20与20日突破入场、MA20或原5%风险阈值退出，全部使用同一全市场历史快照、最多5仓共享资金、每边0.15%成本、T+1与相同估算限价。与初始60股独立资金回放的差异另列，不混为一种策略。

在看本轮结果前固定7个方案：
1. 突破幅度从大到小，原全市场失败控制组。
2. 突破幅度从小到大，避免最急促的拉升。
3. 近20日估算日均成交额从大到小。
4. ATR/现价从小到大。
5. 信号日前19个价格变化的趋势效率从大到小（累计方向变化/绝对变化总量，排除信号日的跳涨）。
6. 信号日前20日涨幅/当日ATR比例从大到小。
7. 趋势效率排序，额外要求量比1.2至3、当日收盘不低于开盘、近20日估算日均成交额不低于1亿元；这是额外过滤实验，单独标注。

除第7组，所有方案使用完全相同的合格信号集合，只改排序。排序平局用估算成交额与股票代码稳定裁决。量价统计不称实际资金流。
