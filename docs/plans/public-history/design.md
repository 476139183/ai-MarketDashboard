# 公开历史样本接入

- 范围：FinMind 美股日线与 Hugging Face `mito0o852/OHLCV-1m` 月度 Parquet；用于历史研究，先实测后扩大下载。
- 数据隔离：独立 SQLite，日线与分钟线分表，不覆盖实时报价；日线保留原始 OHLCV 和独立 Adj_Close，不拿调整收盘拼接未调整高低价。
- 可复核：下载固定仓库 revision，核对文件长度和 SHA256，保留本地清单；默认整批下载预算256MiB；仅抽样月份与股票，缓存可重复使用。
- 质量：严格核对股票、时间范围、时区、OHLC、量能、重复时间；不填补缺失分钟。报告真实覆盖、缺量、缺口和完整交易日数，不用上传者宣称年份代替实际样本。
- 消费：现有冻结规则回放支持显式 source 和独立数据库；日线热身来自相同分钟源，不混合 FinMind 与未知复权分钟价格。
- 边界：本轮不自动优化或更新实盘规则，不下载全库，不调用 AI，不把数据文件上传 GitHub。A 股供应商不在这两个美股源中。
