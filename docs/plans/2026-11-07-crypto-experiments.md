# 加密合约多策略实验预声明

用户约束：BTC / ETH / SOL，双向合约，10x，每笔开仓前净值20%保证金，组合开仓总保证金上限60%，最多三币各一仓。数据冻结在2026-08-07 08:00 UTC—2026-11-07 08:00 UTC。该预声明写于本轮候选策略批量回放之前；最近一月和旧策略结果已被观察，不声称完全未触碰的样本外测试。

## 固定42个候选

价格策略9个：2日 / 7日时间序列动量（12/42根4h）；Donchian20入场/10退出、55入场/20退出；EMA20/50回调收复、ADX14门槛20/25；Bollinger20/30根、2σ回归且ADX14<20；日SMA10/40对照。突破通道排除当前信号线，所有信号在4h收盘后计算；日信号只用完整UTC日线。

每个价格策略分别运行固定价格止损2%/止盈4%，以及波动退出版本：2×ATR20/价格，止损幅度限制在0.5%—4%，不设固定止盈，靠策略退出状态离场。形成18个候选。ATR版本仍按保证金20%定仓，不冒称复现海龟按波动反比定仓。

另保留3个控制：原4h EMA20/50斜率策略、其多空反转、已收盘日线MA20/60顺势过滤。

因子消融固定三个种子（日线过滤EMA、Donchian20 ATR、7日动量ATR）各加7个仅控制入场的条件：主动买卖差、OI币量增长、相对成交量RV≥1.2、OI周转率≥过去20期中位数、价格位于近似POC顺势一侧、账户多空比及历史资金费拥挤回避、综合至少3/4得分且不拥挤。合计21个因子候选，加上前述21个共42个。

综合评分4项：方向×主动买卖差/(总量)≥0.05；OI币量变化>0；RV≥1.2且相对OI周转活跃度≥1；价格在近7日5m近似量价POC的方向一侧。拥挤定义为过去42期账户比的前10%且上一已结算资金费>0.01%时不加多；后10%且资金费<-0.01%时不加空。阈值是本次预设假说，不进行参数寻优。

## 因果与账目

统计4h桶按起点时间解释，可用时刻为ts+4h+5m，因此4h决策点实际使用至少一个完整统计期滞后的数据。taker显式unit=0并与5m基础币成交量聚合核对。数据初审发现部分统计总量与K线成交量有口径差异，原因未获官方确认；不改写任一来源。订单流因子及综合因子在相对差异超过1%的统计期停止新增入场，保留差异与排除计数；1%为本次质量容忍假设，不以收益选择。OI使用币量，避免美元OI被价格污染。资金费因子只用决策前已经结算且经过5m缓冲的实际费率，不用未来费率。

密集区为近7日5m OHLCV近似：按典型价格分50格累计基础币成交量，不能还原真实逐笔笔数或完整逐价成交量。RV是时间活跃度，成交量/OI是周转代理，POC是近似价格密集区，三者分别标注。

入场触发与持仓退出状态分开。首次触发后至少等下一根5m开盘，止损后不因持续状态自动当成新的通道突破；新触发才可再入。每个4h周期方向最多一次。5m开盘决策在本根未来高低价平仓前执行，避免提前释放资金和仓位。

逐仓资金费直接改变该持仓保证金，另记初始保证金；不能同时从现金和强平缓冲重复扣除。新开仓时，若加上已有保证金会超过含即期费用/滑点后的净值60%，缩小本笔到剩余额度。持仓后净值变化造成比例漂移不强制再平衡。标记价触及强平边界而OHLC无法确定先后时保留失败试验，要求更细数据，不把失败试验删掉后只报告幸存者。

## 比较与选择

相同手续费每边0.06%、不利滑点每边0.05%、历史实际资金费及5m标记价；完整60日以上日线预热、7日密集区预热、全段标记价与因子统计覆盖。

分别回放完整三个月，以及8/7—9/7、9/7—10/7、10/7—11/7三段，各段重新从10,000 USDT、空仓开始。完整区间结果单独复利，不将分段收益直接相加。

候选筛选仅用前两段组合结果：两段净收益都>0、每段至少5笔、各段5m收盘最大回撤≤30%，再按两段较低收益率排序、较高回撤作为次排序；不以最后一月最佳结果挑选策略。若无候选通过，直接报告无通过者。最近月已经参与先前讨论，其检查结果仍不等于独立未见数据。对入围模型及基线再进行费用/滑点翻倍压力检验。

所有42候选、失败原因、分币结果、费用和强平检查状态都写入台账。策略文字出处与金融实证限制来自独立研究笔记，4h参数是本项目实验假说，不把论文较长周期证据当成已验证的4h盈利承诺。
