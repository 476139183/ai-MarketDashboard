# A股短期超跌反转：固定规则

## 修改策略
- 选股从“强势股继续上涨”改为“流动性合格股票的短期超跌反转”；旧原型保留，不修改其参数或历史结果。
- 昨日30根以上完整日线、最近25日与市场同步；名称无ST/退市；20日平均价格乘股数≥1亿元。
- Wilder RSI(2)≤20；昨日收盘比MA5低至少0.5ATR；收盘位于当日区间上方40%（区间内位置≥0.6），要求已有一定收复迹象。
- 市场急跌禁入：指数最近一日跌幅达2.5%或5日跌幅达6%。不用“沪深300必须在MA20上方”作为唯一开关。
- 夜间冻结原始止损为昨日低点−0.25ATR，目标为昨日MA5。买入区下沿=max(昨日收盘−0.5ATR,止损＋0.1ATR)，上沿=min(昨日收盘＋0.5ATR,MA5−0.25ATR)。不补造目标空间。
- 盘中至少两根已完成15分钟线：后一根阳线收复前线高点和估算VWAP后，后续新报价仍在昨日计划区才买。14:30后不新开仓。
- 单票不超过账户已保存的原预算；含止损滑点和双边成本的计划风险≤权益0.5%，仍受原最大持仓数和整手限制。不是账户本金或杠杆调整。
- 最早T+1，当前报价触及冻结均值目标/原止损，或上一完整日线失守原反转低点/RSI(2)≥70时退出。没有无条件次日卖出，也不将MA10旧策略退出自动叠加到新仓。
- 原持仓保留入场规则；每票同一信号日只执行一次。

## 检验（查看本策略结果前登记）
- 使用已修复的收盘观察/后续开盘撮合版本，原44只开发、同44只后续、独立124只后续分别报告。
- 默认与双倍成本下均不得亏损；开发收益必须大于旧基线；最大收盘权益回撤≤5%。
- 三组默认合计至少20笔已平仓，后续合计至少5笔；原始输入指纹、时段与股票隔离必须通过。
- 数据已经参与其他候选比较，不称严格未见样本外；即使通过也只作为用户授权的前向模拟新买入候选，不认定月化10%已验证。
- v1结果保留后，仅增加v2经济性约束：下单前按实际数量、滑点与双边费税计算，净均值目标收益/含成本止损风险≥1；不改RSI、收盘位置或市场阈值。另报固定同一批成交的双倍成本收益，不能靠成交路径变化掩盖成本脆弱性。
- 未通过则不发布；不按这些后续结果继续搜索本规则阈值。
- v2开发样本亏损，保留结果。v3仅替换成交经济性条件为“同数量、双倍滑点及费税后，到冻结MA5的预计净收益为正”，取消1R条件；信号阈值不变。此规则在查看新增200只结果前冻结，历史开发集已经复用，不能作为独立验证。
- 若后续笔数不足，补样方式固定为：从2026-11-03历史全沪深证券名单中排除原44只与原独立124只、当时ST/退市证券；按代码SHA256固定排序取200只。完整采集并评估这一批及与原124只合并的股票组，不按期间涨幅选股、不在中途达到笔数时停止。若取不到历史名单，不用当前名单冒充。

## 依据与边界
- 独立假设：日内追涨在已检验样本中缺乏收益，尝试短期反转机制。
- [Shi等2015](https://arxiv.org/abs/1505.00328)为1997～2012年月频反转研究，不能证明本策略日内RSI规则有效。
- [Shi与Zhou2017](https://arxiv.org/abs/1702.07374)讨论周期与标的特征差异；本方案不声称复现其组合。
- 15分钟采样无盘口与区间内止损成交还原，存在存续/选股及公司行动偏差；T+1、跳空和跌停可令实际损失超过计划风险。
