# A股日线趋势回踩收复：固定候选规则

## 决策与假设
- 旧开盘突破候选保持关闭；原回踩策略作为对照。
- 假设：以日线趋势决定持有周期，盘中只负责确认回踩结束，减少追涨和日内噪声退出。
- 夜间准入：沪深普通股、无当时已知ST/退市；25日同步日线；上行MA20，收盘不低于MA20的99%；20日收益比指数高2个百分点；20日日均价格乘股数≥1亿元。
- 过热限制：收盘不高于MA5＋1ATR，最近3日触及MA5＋0.25ATR；候选按距MA5的ATR距离优先，最多20只。
- 市场急跌禁入：指数5日跌幅达3%或20日跌幅达10%。不使用“必须站上MA20”的二元开关。
- 入场：前一完整15分钟线触及MA5＋0.5ATR以内，后一完整线收复MA5和估算VWAP、上破前线高点、阳线且成交量不低于此前3根均量80%。
- 买区：昨日日线MA5−0.25ATR至MA5＋0.5ATR；原止损为昨日已知5日最低价−0.2ATR；区间上沿到止损不超过6%。等待后续开盘/真实新报价，不在产生信号的收盘成交。
- 资金：每票原预算一半，含买卖费用及止损滑点的计划风险≤权益0.25%；沿用原总持仓上限、整手、T+1。
- 退出：原结构止损；完整日线跌破MA20；仅在开仓后形成、左右各两根完整日线确认的支撑位提高保护价。无固定小目标止盈，无到期强制卖出。

## 验证顺序与发布门槛（先登记，再查看结果）
1. 原44只8月4日～11月3日：开发检验，收益为正，成本翻倍收益不为负，最大收盘回撤≤3%。
2. 同44只11月4～11日：时间检验，默认及双倍成本收益不为负。
3. 11月3日已存档池中不属于原44只的普通股票，11月4～11日：股票维度检验，默认及双倍成本收益不为负。
4. 开发与两组后续合计至少20笔已平仓，后续合计至少5笔；否则样本不足，不能发布。
- 任一失败：保留结果，不使用后续集调参，不接管现账户新买入。
- 当前历史池仍有限；15分钟开盘假设不能验证真实盘口、深度与涨跌停排队。

- 开盘仅使用当根open及此前已完成K线；收盘只准备/更新结构，禁止在同一收盘买卖。
- 同分钟的收盘与后续开盘以模型内事件顺序区分；不声称存在真实毫秒级报价。
- 旧报告保留，新报告显式标记回放版本，不覆盖前向账本。
