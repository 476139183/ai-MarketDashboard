# 实施顺序

依据：[固定规则与门槛](design.md)。

1. `a_share_paper.py:step(prepare_only=...)` 与 `a_paper_research.py:bar_observations/replay`：先用构造行情证明额外延迟，再建立收盘观察/后续开盘撮合；前向来源拒绝观察模式。
2. `markets/a/trend_reclaim.py` 与独立测试：昨日准入、盘中收复、日线结构退出；未来、缺根、过热、急跌及T+1测试。
3. `a_share_paper.py:approved_plans/step`：按入场模式路由，研究来源可评估；未发布候选不能用于前向新买入。
4. 独立研究脚本：复用原账目，固定旧44只开发、同股后续、独立股票后续；所有原始输入、哈希、逐笔、月份和成本压力结果留存。
5. 只有全部门槛通过才生成新雷达计划并用于用户授权的现账户新买入；不重置旧仓和历史。

验收：相关Python、Node用例全部通过；原回踩/未发布突破通道行为保持；研究无同收盘成交，无未来值影响前段动作；源账本不变。
