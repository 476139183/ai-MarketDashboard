# 国内商品期货回测设计

## 1. 决策表
| ID | 决策 | 选定 | Why |
|---|---|---|---|
| D1 | 参考与实现 | 参考VeighNa CTA、Backtrader、TqSdk，独立实现轻量日线研究器 | 保持当前标准库部署，不要求新增行情账号 |
| D2 | 策略 | SMA20/60方向基准、Donchian20/10收盘突破；共同2ATR14保护 | 固定规则供比较，不自动挑收益最高者上线 |
| D3 | 合约 | 仅四位YYMM月份合约，不接受连续代码 | 没有可信换月映射，避免拼接价差制造利润 |
| D4 | 撮合 | 前收盘信号、后开盘成交；保护止损处理跳空 | 避免同根收盘信号同价成交的前视 |
| D5 | 成本与风控 | 每手/名义费率、平今倍数、tick滑点、整数手、保证金占用上限 | 期货独立资金与费用语义 |
| D6 | 交付 | 期货页显式运行、策略比较、曲线、逐笔记录；保存真实样本报告 | 结果可复核，不触碰模拟账户 |

## 2. 契约边界
- `POST /api/futures/backtest`显式启动；`GET /api/futures/backtest?id=...`查询；同源限制、请求长度和参数验证。
- 默认单合约1手，研究参数明确可编辑；合约乘数/最小价位与账户保证金、费用假设分开。
- 使用最近至多300根完整日线；排除未收盘、交割月份及之后数据，不自动延长或补齐缺失记录。
- 两策略各自独立本金；输出全段、成本翻倍与尾段从空仓重新运行结果。尾段不是未经观察的严格样本外。
- 保证金不是买入成本；权益=已实现余额+浮盈亏。手续费扣一次，滑点进入成交价，不重复扣减。
- 标记到日收盘；保证金不足停止开仓并在下一可成交开盘退出。零成交量或一字线保守不撮合，结束时不可成交则保留未平头寸并提示。
- 不跨月份换仓、不做完整强平/交割/涨跌停队列/历史动态保证金重建；不得描述为实盘执行收益。

## 3. Trade-off
- 完整vn.py接入适合已有本地历史数据库；TqSdk适合有账号与数据权限。当前采用独立事件循环，记录参考来源和与参考策略的差异。
- 仅月份合约牺牲长时间连续样本，换来明确成交身份；缺少样本时明确拒绝或提示，禁止回退到连续图。

## 4. 验收
- 未来数据追加不改变过去信号；形成中极值不能改变结果。
- 多空、乘数、每边费用、平今、tick滑点、跳空止损、保证金不足、尾段重置均有数值测试。
- 交易净盈亏与期末权益可对账，成本翻倍不重复扣滑点；历史结果不会自动加载或触发交易。
- 浏览器显式执行可见、错误可见、迟到结果隔离；真实RB月份合约完成一次端到端回测。

## 5. 范围
- in：两个固定基准、日线、单月份合约、资金曲线与逐笔记录。
- out：策略寻优、全市场排行榜、自动换月、分钟/tick回测、真实或模拟账户策略切换。
