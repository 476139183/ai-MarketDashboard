# 指标与走强雷达设计
## 1. 决策
| ID | 选定 | Why |
|---|---|---|
| D1 | 个股页本地按完整历史计算MA、MACD、RSI、BOLL、ATR及相对量 | 不依赖AI；切换显示区间不改变指标热身 |
| D2 | 独立全市场A股走强研究雷达 | 原热榜100票与单一突破/大盘门槛会漏掉连续走强个股 |
| D3 | 底部修复、初步转强、连续走强、温和放量突破、回踩再启动固定规则 | 识别已经发生的结构，不能预测保证未来上涨 |
| D4 | 研究结果独立于交易候选与模拟账户 | 新筛选未经样本外收益验证 |
## 2. 契约
- 指标按所选K线及之前数据计算；参数与算法种子公开。未收盘标为形成中，缺失不补零。
- 只查询页面不启动AI、全市场取数、账户开关。全市场扫描显式POST后台执行，GET只读并显示进度、日期、覆盖和失败。
- 旧雷达与所有账户、持仓、策略开关保留。新名单不能进入approved_plans。
- Sina全A证券名单与未复权完整日线；只作当前证券名单研究，不冒充历史全市场回测。
## 3. 验收
- 指标固定数值、热身、未来数据不影响历史、缺失量能、切换标的清空；完整数据与短数据都可显示。
- 趋势样例命中、暴涨过热排除、风险证券/停牌/缺失/重复日期排除；无未来数据，规则不依赖指定代码。
- 覆盖不足与无命中分开；原账本不写入。真实源、历史逐日回放与390px页面验证。
## 4. 范围
- A/美原股指标面板；A股研究雷达。加密/期货策略与自动交易不变。
