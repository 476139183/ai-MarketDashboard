# 国内商品期货分析设计

## 1. 决策表
| ID | 决策点 | 候选 | 选定 | Why |
|---|---|---|---|---|
| D1 | 市场 | 国内商品 / 金融 / 海外 | 国内商品 | 用户确认 |
| D2 | 行情 | 新浪公开源 / 付费终端 | 新浪公开源 | 已实测取得报价与 OHLCV、持仓量，无新增依赖 |
| D3 | 分析 | 连续图观察 / 自动交易 | 连续图及指定月份合约观察 | 首版聚焦分析，连续价格不作为可成交合约 |
| D4 | 指标 | 新策略 / 描述统计 | SMA20/60、ATR14、20根支撑压力、量仓变化 | 提供可解释历史结构，不迁移加密研究结论 |
| D5 | 加载 | 同步请求 / 后台缓存 | 后台缓存 | 源延迟不阻塞 HTTP，请求失败明确保留快照状态 |

## 2. 契约边界
- 页面 `/futures`；只读 API `/api/futures`、`/api/futures/chart?symbol=RB0&period=day`。
- 默认12个品种：RB、AU、AG、CU、AL、SC、FU、M、Y、P、C、I；允许对应品种的3/4位月份代码。
- 周期 day、5、15、30、60；不合成跨休市分钟线。源分钟戳为结束时间，日线日期为源交易日。
- 当天及未来日期日线保守视为形成中；分钟线结束后60秒才参与统计。所有指标仅取完整线。
- 缺值保持 null；昨结算是涨跌基准；源报价时间、采集时间分别展示。超过120秒标为休市或延迟，不猜测交易日历。
- 有界缓存、并发和错误重试间隔；数据源失败保留旧数据并显示错误及采集时间。
- 不修改模拟账本、现有策略和账户配置。

## 3. Trade-off
- 主力连续可快速了解品种走势，但换月可能造成不连续；保留代码、连续标识和换月提示，可输入具体月份合约。
- 日线保守确认避免夜盘跨日与节假日产生伪收盘结论，代价是当日日线要到次日才参与统计。

## 4. 验收指标
- 报价字段、时区、涨跌基准、夜盘日期忠实保留；形成中高价不改变已收盘指标。
- 空响应、无效数值、重复冲突、过期快照和并发重复请求均有可见状态。
- 切换标的清空旧图，迟到响应不能覆盖当前标的；来源字符串安全渲染。
- 原股票、加密合约及模拟路径保持既有行为。

## 5. 范围
- in scope：国内商品行情表、品种筛选、月份合约查询、日/分钟图、量仓与技术结构说明。
- out of scope：股指国债、海外期货、自动下单/模拟、交割与保证金计算、基本面预测和完整交易日历。
