# 入围策略逐笔复盘与有限调整

本轮在原42组结果和逐笔轨迹已知后进行，全部属于事后探索，不是新的样本外验证。用户配置保持10x、单笔保证金20%净值、新开仓组合60%上限。

主候选仍为原筛选唯一入围的bollinger_20_atr，日SMA10/40仅作高回撤对照。复核完整三个月和独立最近月的每笔交易：已收盘信号/入场、数量、止损、费用、逐仓资金费、退出原因与时序、逐笔净值对账。输出全部23笔三个月交易及3笔独立最近月交易，不因亏损删除。MFE/MAE仅统计确定处于持仓的完整5m及入退场参考点，排除根内退出所在K线未知的前后路径，不把事后最大浮盈当成可实现收益。

在查看本轮调整收益前冻结以下六个单项版本，不做组合/参数网格：

1. 中轨空间>0：信号收盘仍在入场方向的中轨前方，避免回归已结束再开仓。
2. 成本空间：方向*(中轨/收盘-1) >= 3 * [2*(0.0006+0.0005)] = 0.66%。这是静态交易成本代理，不包含持仓未知资金费，不是保证收益。
3. ADX不增强：当前ADX14<=三根4h前ADX14，其余条件不动。
4. 日线同向：仅在上一完整UTC日线SMA10/40方向与开仓方向一致时开仓。
5. ATR止损由2倍改为1.5倍，保持0.5%—4%限制。
6. ATR止损由2倍改为2.5倍，保持0.5%—4%限制。

前四项只过滤新增入场，持仓退出状态不改；后两项只改新仓止损。原版加六个调整，共七个版本，各做全段/开发1/开发2/最近月以及BTC/ETH/SOL/组合账户=112次，再各做全段/最近月组合成本翻倍=14次。所有失败均保留。

选择仅根据前两段开发结果：两段各收益>0、各>=5笔、各回撤<=原版两段最差回撤，按两段较低收益排序。只有较低收益超过原版，才称为开发期改进候选；否则保留原版。最近月及成本压力仅披露，不反过来修改阈值。重用开发段仍存在选择偏差，调整即使通过也必须等待新数据前向验证。不能用回放时点后的走势修改当笔信号。
